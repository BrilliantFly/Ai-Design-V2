## 1. 数据表设计

建表方式对齐 `BizSchemaMigration`：`@PostConstruct + JdbcTemplate`，`tableExists` / `ensureColumnExists`。

### 1.1 `ai_opencode_config`（opencode 服务配置）

```sql
CREATE TABLE IF NOT EXISTS ai_opencode_config (
  id              BIGINT       NOT NULL AUTO_INCREMENT,
  base_url        VARCHAR(255) NOT NULL COMMENT 'opencode serve 地址，如 http://127.0.0.1:4096',
  basic_username  VARCHAR(128) NULL COMMENT 'HTTP Basic 用户名（可空）',
  basic_password  VARCHAR(512) NULL COMMENT 'HTTP Basic 密码（AES 加密存储）',
  default_model   VARCHAR(128) NULL COMMENT '默认模型 ref，如 opencode/space-bunny-free',
  enabled         TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '是否启用',
  remark          VARCHAR(255) NULL,
  create_by       VARCHAR(64)  NULL,
  create_time     DATETIME     NULL,
  update_by       VARCHAR(64)  NULL,
  update_time     DATETIME     NULL,
  del_flag        CHAR(1)      NOT NULL DEFAULT '0',
  PRIMARY KEY (id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='opencode 服务配置';
```

> 单行配置：约定 `id=1` 为当前生效配置；设置页保存即 upsert 该行。

## 2. 后端接口设计

统一返回 `AjaxResult<T>`（`code=0/1` 均视为成功）。

### 2.1 配置类

| 方法 | 路径 | 入参 | 说明 |
|------|------|------|------|
| GET | `/api/ai/config` | — | 获取当前配置（密码脱敏） |
| POST | `/api/ai/config` | `{ baseUrl, basicUsername, basicPassword, defaultModel, enabled }` | 保存配置（密码 AES） |
| POST | `/api/ai/config/test` | 同上 | 连通性测试，不落库 |

### 2.2 模型类

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/ai/models` | 列出全部模型，`free` 字段标记免费 |
| GET | `/api/ai/models/free` | 仅返回免费模型 |

响应：

```jsonc
{
  "code": 0, "msg": "ok",
  "data": [
    { "id": "opencode/space-bunny-free", "name": "Space Bunny (Free)",
      "providerID": "opencode", "free": true, "context": 128000 }
  ]
}
```

### 2.3 会话与对话类

| 方法 | 路径 | 入参 | 说明 |
|------|------|------|------|
| POST | `/api/ai/session` | `{ title? }` | 创建会话（后端转发 `POST /session` 并落库） |
| GET | `/api/ai/session` | `?pageNum&pageSize` | 列出当前用户会话 |
| GET | `/api/ai/session/{id}` | — | 会话详情 + 历史 message 列表 |
| DELETE | `/api/ai/session/{id}` | — | 删除会话（同步删除 opencode 侧） |
| POST | `/api/ai/chat` | `{ sessionId, content, model? }` | 发送消息（流式：SSE 增量返回） |
| POST | `/api/ai/chat/abort` | `{ sessionId }` | 中断当前生成 |

### 2.4 流式对话接口（核心）

```
POST /api/ai/chat
Content-Type: application/json
Accept: text/event-stream

{ "sessionId": 123, "content": "你好", "model": "opencode/space-bunny-free" }
```

后端流程：

1. 写入 `ai_chat_message`（user，status=done）。
2. 调 `OpenCodeClient.promptAsync(opencodeSid, req)` → `POST /session/:id/prompt_async`，拿到 204。
3. 返回 `SseEmitter`（超时 120s）。
4. 启动后台线程订阅 opencode `GET /event`，过滤事件：
   - `message.part.delta` + `field=="text"` → `emitter.send(SseEmitter.event().data(delta))`
   - `session.status` + `type=="idle"` → 拼接完整 assistant 文本，写 `ai_chat_message`（assistant, status=done），`emitter.complete()`
5. 异常：`emitter.send(error)` + `emitter.completeWithError()`，消息 status=error。

SSE 帧格式（对前端）：

```
data: {"type":"delta","text":"你"}

data: {"type":"delta","text":"好"}

data: {"type":"done","messageId":456}
```

### 3.2 构造请求头

```java
private HttpHeaders buildHeaders() {
    HttpHeaders h = new HttpHeaders();
    h.setContentType(MediaType.APPLICATION_JSON);
    String u = current.basicUsername, p = current.basicPassword; // 来自 DB 或配置
    if (StrUtil.isNotBlank(u)) {
        String token = Base64.encode(u + ":" + (p == null ? "" : p));
        h.set("Authorization", "Basic " + token);
    }
    return h;
}
```

### 3.3 模型清单（自动翻页）

opencode `/api/model` 是分页路由，信封 `{ location, data: [], cursor: {} }`。实现循环取下一页直到 `cursor` 为空：

```java
public List<Model> listModels() {
    List<Model> all = new ArrayList<>();
    String cursor = null;
    do {
        String url = baseUrl + "/api/model" + (cursor == null ? "" : "?cursor=" + cursor);
        ResponseEntity<ModelPage> resp = rest.exchange(url, GET, entity(), ModelPage.class);
        all.addAll(resp.getBody().getData());
        cursor = resp.getBody().getCursor() == null ? null : resp.getBody().getCursor().getNext();
    } while (cursor != null);
    return all;
}
```

### 3.4 SSE 订阅（WebClient）

```java
public Flux<String> subscribeTextDelta(String opencodeSid) {
    return webClient.get().uri(baseUrl + "/event")
        .accept(MediaType.TEXT_EVENT_STREAM)
        .retrieve()
        .bodyToFlux(String.class)     // 每帧 JSON
        .filter(frame -> frame.contains("message.part.delta"))
        .map(this::extractDelta);     // 解析 {payload.properties.delta}
}
```

> 注意：`/event` 是全局流，需按 `payload.properties.messageID` 过滤当前会话消息（或按 `sessionID` 关联）。

### 3.5 SSRF 防护

保存配置时校验：

```java
void validateBaseUrl(String url) {
    URI u = URI.create(url);
    if (!allowedSchemes.contains(u.getScheme())) throw new BizException("协议不允许");
    String host = u.getHost();
    if (isPrivateOrLoopback(host) && !allowIntranet) throw new BizException("内网地址需管理员开启");
}
```

## 4. AiChatController 草案

```java
@RestController
@RequestMapping("/api/ai")
public class AiChatController {

    @PostMapping("/chat")
    public SseEmitter chat(@RequestBody ChatRequest req, Principal user) {
        SseEmitter emitter = new SseEmitter(120_000L);
        aiChatService.streamChat(req, user.getName(), emitter);
        return emitter;
    }

    @GetMapping("/models/free")
    public AjaxResult<List<ModelVO>> freeModels() {
        return AjaxResult.ok(aiChatService.listFreeModels());
    }

    @PostMapping("/session")
    public AjaxResult<SessionVO> createSession(@RequestBody SessionCreateDTO dto, Principal user) {
        return AjaxResult.ok(aiChatService.createSession(dto, user.getName()));
    }
}
```

### AiChatService.streamChat 核心逻辑

```java
public void streamChat(ChatRequest req, String username, SseEmitter emitter) {
    // 1. 落库 user 消息
    aiChatMessageMapper.insert(userMsg);
    // 2. 调 opencode prompt_async
    String opencodeSid = session.getOpencodeSid();
    client.promptAsync(opencodeSid, req);
    // 3. 订阅 /event，过滤 delta 转发
    StringBuilder full = new StringBuilder();
    client.subscribeTextDelta(opencodeSid)
        .doOnNext(delta -> {
            emitter.send(SseEmitter.event().data(Map.of("type","delta","text",delta)));
            full.append(delta);
        })
        .doOnComplete(() -> {
            aiChatMessageMapper.insert(assistantMsg(req, full.toString()));
            emitter.send(SseEmitter.event().data(Map.of("type","done")));
            emitter.complete();
        })
        .doOnError(emitter::completeWithError)
        .subscribe();
}
```

## 7. 错误处理

| 场景 | 处理 |
|------|------|
| opencode 未启动 / 超时 | 返回 `AjaxResult.fail("AI 服务暂不可用")`；SSE 推 `{type:"error",msg}` |
| opencode 会话不存在 | 重新 `POST /session` 创建并更新本地映射 |
| 流式中断 | `emitter.completeWithError`；消息置 `status=error` |
| 并发会话超限 | 拒绝新会话，提示「当前 AI 助手繁忙」 |
