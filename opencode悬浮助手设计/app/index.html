opencode 悬浮助手 · 原型预览

本页演示「调用 opencode 免费模型接口 + Vue/uniapp 悬浮按钮对话」的交互形态。

方案要点：

1. 后端 know-boot-ai 封装 opencode HTTP API（/session、/event、/api/model）。

2. 默认使用 OpenCode Zen 内置免费模型；管理员可在模型库接入 OpenAI、OpenRouter、Gemini、Anthropic、Ollama 等。

3. 悬浮球可拖动 + 吸附边缘，点击展开对话抽屉。

4. 流式对话走 SSE（message.part.delta 逐字输出）。

5. App / 小程序端降级为非流式一次性返回。

原型包含：悬浮球、对话抽屉、模型选择、设置弹窗（管理员，含多 Provider 配置 + 模型库管理）、流式打字机效果、中断生成。
