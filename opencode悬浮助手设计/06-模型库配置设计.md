# 06 - 模型库配置设计

> 对应模块：`know-boot-ai` + `know-vue` 管理端
> 定位：在「仅用 opencode 内置免费模型」基础上，扩展为**可配置多 provider 模型库**——管理员可接入 OpenAI、OpenRouter、Google Gemini、Anthropic、Ollama 等，并管理可用模型清单。

---

## 1. 设计目标

1. **多 provider 接入**：支持配置 OpenAI、OpenRouter、Google Gemini、Anthropic、Mistral、Groq、Ollama（本地）、自定义 OpenAI 兼容服务。
2. **凭证后端托管**：所有 API Key 经后端保管（AES 加密），同步到 opencode，前端不持有。
3. **模型库管理**：从 opencode 拉取全部可用模型，管理员可**启用/禁用**具体模型、标记推荐、排序。
4. **免费/付费标识**：沿用 `cost.input===0 && cost.output===0` 判定，模型库与用户侧下拉均打「免费」标签。
5. **用户侧选择**：对话时仅从「已启用」模型中选择；默认选中第一个免费模型。
6. **连通性测试**：每个 provider 保存前可单独测试。

---

## 2. 支持的 Provider 类型

| Provider | 类型 | 需 API Key | opencode providerID | 配置方式 | 免费模型 |
|----------|------|-----------|---------------------|---------|---------|
| OpenCode Zen | 内置(免费) | 否 | `opencode` | 开箱即用 | 14+ 个 |
| OpenAI | 内置 | 是 | `openai` | `PUT /auth/openai` | 无（付费） |
| OpenRouter | 内置 | 是 | `openrouter` | `PUT /auth/openrouter` | `:free` 后缀变体 |
| Google Gemini | 内置 | 是 | `google` | `PUT /auth/google` | Flash 免费档 |
| Anthropic | 内置 | 是 | `anthropic` | `PUT /auth/anthropic` | 无（付费） |
| Mistral | 内置 | 是 | `mistral` | `PUT /auth/mistral` | 部分免费 |
| Groq | 内置 | 是 | `groq` | `PUT /auth/groq` | 免费档 |
| Ollama（本地） | 内置 | 否 | `ollama` | baseURL 配置 | 全部免费 |
| LM Studio（本地） | 内置 | 否 | `lmstudio` | baseURL 配置 | 全部免费 |
| 自定义 OpenAI 兼容 | 自定义 | 是 | 自定义 ID | opencode config 文件 | 取决于服务 |

> **配置方式说明**：
> - **内置 provider**：后端调 opencode `PUT /auth/{providerID}` 推送 API Key；本地 provider（Ollama/LM Studio）通过 opencode config 设置 `baseURL`。
> - **自定义 provider**：后端生成 opencode config 片段写入 `~/.config/opencode/opencode.json` 的 `provider` 段（需后端与 opencode 同机或有文件访问能力）。

## 3. 数据表设计

### 3.1 `ai_model_provider`（provider 配置）

```sql
CREATE TABLE IF NOT EXISTS ai_model_provider (
  id            BIGINT       NOT NULL AUTO_INCREMENT,
  provider_id   VARCHAR(64)  NOT NULL COMMENT 'opencode providerID，如 openai/openrouter/ollama/custom-xxx',
  name          VARCHAR(64)  NOT NULL COMMENT '展示名，如 OpenAI / OpenRouter',
  type          VARCHAR(32)  NOT NULL COMMENT 'builtin / custom / local',
  api_key       VARCHAR(512) NULL COMMENT 'API Key（AES 加密，本地 provider 为空）',
  base_url      VARCHAR(255) NULL COMMENT '自定义 baseURL（本地 provider / 自定义 provider 用）',
  enabled       TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否启用',
  remark        VARCHAR(255) NULL,
  create_by     VARCHAR(64)  NULL,
  create_time   DATETIME     NULL,
  update_by     VARCHAR(64)  NULL,
  update_time   DATETIME     NULL,
  del_flag      CHAR(1)      NOT NULL DEFAULT '0',
  PRIMARY KEY (id),
  UNIQUE KEY uk_provider_id (provider_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AI 模型 provider 配置';
```

### 3.2 `ai_model_library`（模型库，缓存 opencode 模型清单）

```sql
CREATE TABLE IF NOT EXISTS ai_model_library (
  id            BIGINT       NOT NULL AUTO_INCREMENT,
  provider_id   VARCHAR(64)  NOT NULL COMMENT '所属 providerID',
  model_ref     VARCHAR(128) NOT NULL COMMENT '完整模型 ref，如 openai/gpt-4o / opencode/space-bunny-free',
  name          VARCHAR(128) NOT NULL COMMENT '展示名',
  is_free       TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否免费（cost.input=0 && cost.output=0）',
  context_limit INT          NULL COMMENT '上下文窗口',
  output_limit  INT          NULL COMMENT '输出上限',
  cost_input    DOUBLE       NULL COMMENT '输入单价 USD/百万token',
  cost_output   DOUBLE       NULL COMMENT '输出单价 USD/百万token',
  enabled       TINYINT(1)   NOT NULL DEFAULT 1 COMMENT '是否在用户侧可见',
  recommended   TINYINT(1)   NOT NULL DEFAULT 0 COMMENT '是否推荐（置顶）',
  sort_order    INT          NOT NULL DEFAULT 0 COMMENT '排序',
  last_sync     DATETIME     NULL COMMENT '最近一次从 opencode 同步时间',
  create_time   DATETIME     NULL,
  update_time   DATETIME     NULL,
  del_flag      CHAR(1)      NOT NULL DEFAULT '0',
  PRIMARY KEY (id),
  UNIQUE KEY uk_model_ref (model_ref),
  KEY idx_provider (provider_id, enabled, del_flag)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='AI 模型库';
```

> **关系**：`ai_model_library.provider_id` → `ai_model_provider.provider_id`（逻辑外键，不强约束）。

## 4. 后端接口设计

### 4.1 Provider 配置类

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/ai/providers` | 列出全部 provider 配置（apiKey 脱敏返回 `hasKey` 布尔） |
| GET | `/api/ai/providers/builtin` | 返回 opencode 支持的内置 provider 清单（硬编码枚举） |
| POST | `/api/ai/providers` | 新增/更新 provider 配置（upsert by provider_id） |
| DELETE | `/api/ai/providers/{id}` | 删除 provider（同时禁用其下模型） |
| POST | `/api/ai/providers/{id}/test` | 测试连通（临时构造，不落库） |
| POST | `/api/ai/providers/{id}/sync` | 将凭证同步到 opencode（`PUT /auth/{id}`） |

Provider 配置请求体：

```jsonc
POST /api/ai/providers
{
  "providerId": "openai",        // openai/openrouter/google/anthropic/mistral/groq/ollama/lmstudio 或自定义
  "name": "OpenAI",
  "type": "builtin",             // builtin / custom / local
  "apiKey": "sk-xxxx",
  "baseUrl": null,               // local/custom 时填
  "enabled": true
}
```

### 4.2 模型库管理类

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/ai/library` | 模型库列表（支持 `?providerId=&freeOnly=&enabledOnly=` 过滤） |
| PUT | `/api/ai/library/{id}` | 更新单模型（`enabled`/`recommended`/`sortOrder`） |
| POST | `/api/ai/library/refresh` | 从 opencode `GET /api/model` 全量拉取，upsert 到 `ai_model_library` |

模型库列表响应：

```jsonc
{
  "code": 0, "data": {
    "list": [
      { "id": 1, "providerId": "opencode", "modelRef": "opencode/space-bunny-free",
        "name": "Space Bunny (Free)", "isFree": true, "contextLimit": 128000,
        "costInput": 0, "costOutput": 0, "enabled": true, "recommended": true, "sortOrder": 1 },
      { "id": 2, "providerId": "openai", "modelRef": "openai/gpt-4o",
        "name": "GPT-4o", "isFree": false, "contextLimit": 128000,
        "costInput": 2.5, "costOutput": 10, "enabled": true, "recommended": false, "sortOrder": 2 }
    ],
    "total": 2
  }
}
```

### 4.3 用户侧模型选择（改造既有接口）

`GET /api/ai/models`（及 `/free`）改为从 `ai_model_library` 读取（`enabled=1`），不再每次穿透 opencode：

```jsonc
GET /api/ai/models?freeOnly=false
// 返回 ai_model_library 中 enabled=1 的模型
GET /api/ai/models/free
// 返回 enabled=1 && is_free=1
```

## 5. 同步到 opencode 的逻辑

### 5.1 内置 provider（OpenAI / OpenRouter / Google / Anthropic / Mistral / Groq）

```java
public void syncToOpenCode(AiModelProvider p) {
    if (StrUtil.isBlank(p.getApiKey())) return;
    // PUT /auth/{providerId}  body: { type: "api", key: "..." }
    String url = baseUrl + "/auth/" + p.getProviderId();
    HttpHeaders h = buildHeaders();
    h.setContentType(MediaType.APPLICATION_JSON);
    Map<String, Object> body = Map.of("type", "api", "key", aesUtil.decrypt(p.getApiKey()));
    rest.exchange(url, PUT, new HttpEntity<>(body, h), Void.class);
}
```

### 5.2 本地 provider（Ollama / LM Studio）

无需 API Key，仅需配置 `baseURL`。opencode 的本地 provider 通过 config 文件或环境变量设置 baseURL：

```jsonc
// ~/.config/opencode/opencode.json 片段
{
  "provider": {
    "ollama": { "options": { "baseURL": "http://127.0.0.1:11434/v1" } }
  }
}
```

后端在 `syncToOpenCode` 时：若 `type=local`，生成上述片段合并写入 config 文件（或提示管理员手动配置）。

### 5.3 自定义 OpenAI 兼容 provider

```jsonc
// opencode config 片段
{
  "provider": {
    "custom-myorg": {
      "npm": "@ai-sdk/openai-compatible",
      "options": { "baseURL": "https://my-llm.example.com/v1", "apiKey": "sk-xxx" },
      "models": {
        "my-model-1": { "name": "My Model 1" }
      }
    }
  }
}
```

后端 `syncToOpenCode` 时：若 `type=custom`，读取现有 config，合并 `provider.{providerId}` 段，写回文件。

> **config 文件写入**：仅当后端与 opencode 同机部署时可用；分离部署时降级为「导出配置片段，管理员手动粘贴」。

## 6. 模型库刷新流程

```
管理员点击「刷新模型库」
  → POST /api/ai/library/refresh
  → 后端 GET {baseUrl}/api/model （自动翻页）
  → 遍历返回的 Model[]：
     ├─ 计算 isFree = (cost.input===0 && cost.output===0)
     ├─ upsert ai_model_library (按 model_ref 去重)
     │   - 已存在：更新 name/is_free/cost_*/limit/last_sync，保留 enabled/recommended/sort_order
     │   - 不存在：插入，默认 enabled = isFree（免费模型默认启用，付费默认禁用）
     └─ opencode 侧已删除的模型：标记 del_flag=2（软删除，不真删，保留历史会话引用）
  → 返回 { added: 3, updated: 5, removed: 1, total: 20 }
```

## 7. 管理员 UI（know-vue 新增菜单）

### 7.1 菜单结构

```
AI 助手（新增一级菜单）
├── 模型库管理      /ai/library      → 模型列表 + 启用/禁用
├── Provider 配置   /ai/providers    → provider 卡片列表
└── 服务设置        /ai/config       → opencode 地址（原设置页）
```

### 7.2 Provider 配置页

卡片式布局，每个 provider 一张卡片：

```
┌──────────────────────────────────┐
│ [logo] OpenAI            [启用●] │
│ ┌──────────────────────────────┐ │
│ │ API Key: sk-...****         │ │
│ └──────────────────────────────┘ │
│ [测试连通]  [保存]  [同步到opencode]│
└──────────────────────────────────┘
```

操作：
- **添加 Provider**：下拉选内置类型 或 填自定义。
- **测试连通**：`POST /api/ai/providers/{id}/test` → 调 opencode `GET /provider` 验证 `connected` 含此 provider。
- **同步**：`POST /api/ai/providers/{id}/sync` → 推送凭证到 opencode。

### 7.3 模型库管理页

表格布局：

| 模型 ref | 名称 | Provider | 免费 | 上下文 | 输入$/M | 启用 | 推荐 | 排序 |

| opencode/space-bunny-free | Space Bunny | opencode | ✅ | 128K | 0 | ✅ | ⭐ | 1 |
| openai/gpt-4o | GPT-4o | openai | ❌ | 128K | 2.5 | ✅ | | 2 |
| openai/gpt-4o-mini | GPT-4o mini | openai | ❌ | 128K | 0.15 | ❌ | | 3 |

操作：批量启用/禁用、标记推荐、拖拽排序、[刷新模型库] 按钮。

## 9. 与既有方案的关系

| 既有设计点 | 本文件的影响 |
|-----------|-------------|
| `ai_opencode_config`（单行） | 保留，仅存 opencode 服务地址 + Basic 鉴权 |
| `GET /api/ai/models/free` | 改为查 `ai_model_library`，不再每次穿透 opencode |
| 默认模型 `opencode/space-bunny-free` | 仍为默认，但可被管理员改为其他已启用模型 |
| 用户侧模型下拉 | 从「仅免费」扩展为「全部已启用」，免费打标签 |

## 10. 安全与边界

| 议题 | 处理 |
|------|------|
| API Key 存储 | AES 加密入 `ai_model_provider.api_key`；返回前端只回 `hasKey` 布尔 |
| 自定义 baseURL | 协议白名单（http/https）+ 可选内网允许开关，防 SSRF |
| opencode config 写入 | 仅同机部署可自动写；分离部署导出片段人工粘贴 |
| 凭证同步幂等 | `PUT /auth/{id}` 可重复调用，覆盖式更新 |
| 模型库与历史会话 | 软删除模型（del_flag），历史 `ai_chat_message` 仍可按 model_ref 展示，但新会话不可选 |
| 并发刷新 | `refresh` 接口加分布式锁，防重复拉取 |
