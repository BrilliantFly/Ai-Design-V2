# 03 · 页面结构与布局优化

> 文档版本：V1.0
> 前置文档：[02-设计目标与原则.md](./02-设计目标与原则.md)
> 核心原则：保留全部功能入口，仅调整区块顺序、合并冗余、统一布局尺度。

---

## 一、优化后区块总览

优化后首页自顶向下分为 **7 个区块**（原 10 个，合并 3 处冗余）：

| 序号 | 区块 | 来源 | 首屏可见 |
|------|------|------|----------|
| 1 | Hero 顶栏 | 保留 | ✅ |
| 2 | 今日概要卡片 | 保留（强化） | ✅ |
| 3 | 搜索 + 公告 合并行 | 搜索栏 + 公告条合并 | ✅ |
| 4 | 快捷功能宫格 | 保留（精简） | ✅ |
| 5 | 轮播 Banner | 保留（下移） | 部分 |
| 6 | 热门推荐 | 保留 | ❌ |
| 7 | 常用工具 + 便捷标签 合并 | 两区块合并 | ❌ |

底部导航保持不变。

---

## 二、各区块详细设计

### 区块 1：Hero 顶栏（强化）

**现状问题**：渐变区过高，头像偏小，问候语权重不足，通知铃铛样式普通。

**优化方案**：

```
┌─────────────────────────────────────┐
│  ┌──┐                               │
│  │头│  早上好，张三 ☀️               │  ← 36rpx/700 白色
│  └──┘  今日还有 3 项待办，继续推进    │  ← 22rpx 白色78%
│         [🔔 3]                       │  ← 右上角通知
└─────────────────────────────────────┘
         ↓ 圆角 0 0 32 32，渐变收窄
```

**样式要点**：
- 顶栏高度从约 200rpx 收窄至 `168rpx`（含状态栏），减少首屏占用。
- 头像放大至 `96rpx`，使用主题对比色半透底。
- 问候语 `36rpx / 700`，副标题 `22rpx / 400` 白色 78% 不透明度。
- 通知铃铛改为 `44rpx` 圆形白底半透，badge 使用 `--color-danger`。
- 圆角仅底部 `32rpx`，顶部齐平，形成「顶部沉浸」效果。
- 装饰元素（deco-ring / deco-dot）保留但透明度降至 `0.08`，避免干扰。

---

### 区块 2：今日概要卡片（强化）

**现状问题**：卡片向上浮起 `-22rpx` 叠加在 Hero 上，视觉错位；数字过大与周围不协调。

**优化方案**：

```
┌─────────────────────────────────────┐
│  今日概要                        日程 → │
│  ┌──────────┐ ┌────────┐ ┌────────┐ │
│  │  📋  3   │ │ 🔔 2   │ │ 🛡️ 8   │ │
│  │  今日待办 │ │ 待处理  │ │ 在线设备│ │
│  └──────────┘ └────────┘ └────────┘ │
└─────────────────────────────────────┘
```

**样式要点**：
- 取消 `-22rpx` 上浮，改为 `margin-top: 24rpx` 正常流，与 Hero 底部圆角自然衔接。
- 卡片使用主卡片层级：`--shadow-md` + `28rpx` 圆角 + `24rpx` 内边距。
- 三栏等分，每栏「图标 + 数字 + 标签」垂直排列（原水平排列改为垂直，数字更突出）。
- 数字 `32rpx / 700`，标签 `18rpx / 400` 三级色。
- 图标使用 `36rpx` 方形圆角 `12rpx`，背景为语义色 soft 变体：
  - 待办：`--color-primary-soft` + 主色图标
  - 告警：`--color-danger-soft` + 危险色图标
  - 在线：`--color-success-soft` + 成功色图标
- 右上角增加「日程 →」入口文字（`20rpx` 三级色），强化跳转引导。

---

### 区块 3：搜索 + 公告 合并行（新增合并）

**现状问题**：搜索栏独占一行，公告条又独占一行，两者都是「入口型」组件，浪费纵向空间。

**优化方案**：将搜索栏与公告条合并为一个卡片容器。

```
┌─────────────────────────────────────┐
│  🔍 搜索功能、设备、文档...    📷    │  ← 搜索行
├─────────────────────────────────────┤
│  📢 系统 v2.4 已发布，新增甘特图... › │  ← 公告行（垂直滚动）
└─────────────────────────────────────┘
```

**样式要点**：
- 外层使用次卡片层级：`--shadow-sm` + `24rpx` 圆角。
- 搜索行高 `80rpx`，内边距 `0 24rpx`，无背景色（继承卡片）。
- 扫码按钮 `64rpx` 方形，`--color-primary-soft` 背景 + 主色图标。
- 中间以 `2rpx solid --color-border-light` 分隔线区分搜索与公告。
- 公告行高 `56rpx`，左侧 `📢` 图标 `32rpx`，中间垂直 swiper，右侧 `›` 箭头。
- 整体卡片相比原搜索栏 + 公告条节省约 `40rpx` 纵向空间。

---

### 区块 4：快捷功能宫格（精简）

**现状问题**：宫格 5 列，图标 9 种渐变底色，「更多」按钮用 `•••` 符号。

**优化方案**：

```
┌─────────────────────────────────────┐
│  快捷功能                      全部 → │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐          │
│  │📹│ │📅│ │🎯│ │👥│ │📊│          │
│  └──┘ └──┘ └──┘ └──┘ └──┘          │
│  监控  日程  习惯  客户  数据          │
│  ┌──┐ ┌──┐ ┌──┐ ┌──┐ ┌──┐          │
│  │🔔│ │💳│ │📋│ │📄│ │⋯│           │
│  └──┘ └──┘ └──┘ └──┘ └──┘          │
│  告警  财务  甘特  文档  更多          │
└─────────────────────────────────────┘
```

**样式要点**：
- 保持 5 列布局，但图标背景统一为 `--color-primary-soft`，图标颜色统一为 `--color-primary`。
- 取消每个图标的独立 `premium-icon-g1~g10` 渐变，统一视觉。
- 图标尺寸 `56rpx` 方形，圆角 `16rpx`。
- 标签 `18rpx / 400` 次要色，与图标间距 `10rpx`。
- 「更多」按钮使用 SVG 水平三点图标，背景 `--color-surface-soft`。
- 宫格外层使用容器层级：`--color-surface-soft` 背景 + `28rpx` 圆角，无边框。
- 内边距 `24rpx 16rpx`，行距 `20rpx`。

---

### 区块 5：轮播 Banner（下移 + 弱化）

**现状问题**：轮播占据首屏黄金位置，但内容硬编码且与快捷功能重复。

**优化方案**：将轮播下移至快捷宫格之后，作为「活动推荐」存在。

```
┌─────────────────────────────────────┐
│  ┌───────────────────────────────┐  │
│  │  AI 智能监控升级          🏆  │  │
│  │  实时分析 · 异常告警 · 7x24h   │  │
│  └───────────────────────────────┘  │
│            ● ● ●                     │
└─────────────────────────────────────┘
```

**样式要点**：
- 轮播高度从 `276rpx` 降至 `200rpx`，减少视觉权重。
- 渐变背景保留但饱和度降低，使用 `rgba` 叠层增加质感。
- 标题 `30rpx / 700`，描述 `20rpx` 白色 80%。
- 装饰图标 `🏆` 移至右下角，尺寸 `64rpx`，透明度 `0.25`。
- 指示点居中底部，激活态宽度 `20rpx`。
- 自动播放间隔 `5000ms`。

---

### 区块 6：热门推荐（保留 + 统一卡片）

**现状问题**：推荐卡片缩略图使用 9 种不同渐变，视觉混乱。

**优化方案**：

```
┌─────────────────────────────────────┐
│  热门推荐                    查看全部 │
│  ┌──────┐ ┌──────┐ ┌──────┐ ┌──────┐│
│  │ 📹   │ │ 📅   │ │ 🎯   │ │ 📊   ││
│  │监控  │ │日程  │ │习惯  │ │数据  ││
│  └──────┘ └──────┘ └──────┘ └──────┘│
└─────────────────────────────────────┘
```

**样式要点**：
- 卡片宽度 `220rpx`，圆角 `24rpx`，次卡片层级。
- 缩略图区高度 `120rpx`，背景统一为 `--color-primary-soft`，图标 `48rpx` 主色。
- 标签（tag）移至缩略图右上角，白底主色字 `16rpx`。
- 标题 `22rpx / 600`，描述 `18rpx / 400` 次要色，单行省略。
- 取消每张卡片的独立 `thumbBg` 渐变。

---

### 区块 7：常用工具 + 便捷标签 合并（新增合并）

**现状问题**：常用工具（2 列卡片）与便捷工具（横向标签）分开，且便捷标签内容与概要卡片重复。

**优化方案**：将便捷标签整合为常用工具卡片顶部的「数据概览条」，删除独立的便捷标签区块。

```
┌─────────────────────────────────────┐
│  常用工具                      更多 → │
│  ┌─────────────┐ ┌─────────────┐    │
│  │ 📋 甘特图    │ │ 🔔 告警分析  │    │
│  │ 项目进度追踪  │ │ 异常事件趋势  │    │
│  │ ▓▓▓▓▓░░ 65% │ │ ▓▓▓░░░░ 42% │    │
│  └─────────────┘ └─────────────┘    │
│  ┌─────────────┐ ┌─────────────┐    │
│  │ 📤 报表导出  │ │ ✅ 待办事项  │    │
│  │ 一键生成运营  │ │ 今日优先处理  │    │
│  │ ▓▓▓░░░░ 38% │ │ ▓▓▓▓▓░░ 65% │    │
│  └─────────────┘ └─────────────┘    │
└─────────────────────────────────────┘
```

**样式要点**：
- 2 列网格，间距 `16rpx`。
- 每张卡片使用次卡片层级，顶部色条保留但改为 `4rpx` 高，颜色取自图标语义色。
- 图标 `40rpx` 方形 `14rpx` 圆角，背景 `--color-surface-soft`，图标色主色。
- 标题 `24rpx / 600`，描述 `18rpx / 400` 次要色。
- 进度条高度 `8rpx`，背景 `--color-surface-soft`，填充主色渐变。
- 进度文字 `16rpx` 三级色，右对齐。
- **便捷标签内容已整合进概要卡片与工具卡片，删除独立标签区块**。

---

## 三、优化前后对比总览

| 维度 | 优化前 | 优化后 |
|------|--------|--------|
| 区块数 | 10 | 7 |
| 首屏可见区块 | 5（过载） | 3（聚焦） |
| 硬编码渐变色 | 12+ 种 | 1 种（Hero） |
| 间距取值 | 8 种碎值 | 4 种统一 scale |
| 字号取值 | 7 种 | 5 级 scale |
| 图标风格 | emoji + SVG + 文字符号 | SVG 统一 |
| 卡片层级 | 1 种 | 3 种分层 |
| 功能入口数 | 不变 | 不变 |
