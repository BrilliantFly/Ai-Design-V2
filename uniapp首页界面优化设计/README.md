# 首页界面优化设计方案

> 创建日期：2026-10-15
> 版本：V1.0
> 状态：设计稿
> 范围：仅界面样式优化，不涉及功能逻辑与接口变更

---

## 背景

`know-uniapp` 首页（`src/pages/index/index.vue`）当前存在信息密度过高、色彩混乱、间距不统一、图标风格杂糅、卡片质感单薄等问题，影响视觉品质与信息传达效率。本方案聚焦**界面样式层**的系统性优化，保留全部现有功能入口与交互逻辑。

---

## 优化目标

1. **首屏聚焦**：首屏可见区块从 5 个压缩至 3 个，降低认知负荷
2. **统一 Token**：间距、圆角、字号、阴影、色彩全部抽象为 CSS 变量
3. **清晰层级**：通过字号、字重、卡片分层建立明确视觉层级
4. **图标统一**：全页 SVG 化，淘汰 emoji 作为功能图标
5. **主题适配**：20 套主题下保持一致的视觉品质与对比度
6. **功能零删减**：所有入口、跳转、数据接口保持不变

---

## 核心调整一览

| 调整项 | 优化前 | 优化后 |
|--------|--------|--------|
| 区块数 | 10 | 7 |
| 首屏区块 | 5（过载） | 3（聚焦） |
| 硬编码渐变色 | 12+ 种 | 1 种（仅 Hero） |
| 间距取值 | 8 种碎值 | 4 种统一 scale |
| 字号层级 | 7 种 | 5 级 scale |
| 图标风格 | emoji + SVG + 文字符号 | SVG 统一 |
| 卡片层级 | 1 种 | 3 种分层 |
| 搜索/公告 | 分两行 | 合并为一张卡片 |
| 常用工具/便捷标签 | 两个区块 | 合并（标签整合进工具卡片） |

## 实施约束

### 必须遵守

1. **不删除任何功能入口**：`quickTiles`、`recommendTiles`、`dashboardTools` 数据结构与渲染逻辑保持不变。
2. **不改动跳转路径**：`goLink`、`goMore`、`handleQuickTap` 等方法保持不变。
3. **不改动接口调用**：`getHomeMenu`、`getHomeConfig`、`getTodayStats` 等保持不变。
4. **使用 uni-app 跨端标签**：`view` / `text` / `image` / `swiper`，不引入 `div` / `span`。
5. **样式走主题变量**：禁止新增硬编码色值。

### 建议但不强制

1. 底部导航「新建」Tab 语义建议后续改为「首页」（需配合菜单配置调整）。
2. 轮播内容建议后续由后端动态下发（当前为硬编码）。

## 验收清单

- [ ] 首屏可见区块 ≤ 3 个
- [ ] 无硬编码色值（emoji 除外）
- [ ] 快捷宫格图标背景统一为主色浅底
- [ ] 搜索栏与公告条合并为一张卡片
- [ ] 便捷标签区块已删除，内容整合进概要/工具卡片
- [ ] 卡片圆角、阴影、内边距符合 Token 规范
- [ ] 字号层级符合 5 级 scale
- [ ] 浅色与深色主题下文字对比度达标
- [ ] 所有现有功能入口可正常跳转
- [ ] 入场动效流畅，点击反馈统一
