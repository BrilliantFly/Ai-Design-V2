## 一、主题适配策略

### 1.1 全量变量化

首页所有色值必须取自主题变量，禁止硬编码。需替换的硬编码色值清单：

| 位置 | 原硬编码 | 替换为 |
|------|----------|--------|
| Hero 渐变 | `linear-gradient(135deg, #5b5bd6, #1890ff)` | `linear-gradient(135deg, var(--color-primary), var(--color-minor))` |
| 轮播 slide 1 | `linear-gradient(135deg, #6366f1, #8b5cf6)` | 改为主题色变体（见 1.2） |
| 轮播 slide 2 | `linear-gradient(135deg, #d4956b, #e8b88a)` | 改为主题色变体 |
| 轮播 slide 3 | `linear-gradient(135deg, #22b573, #4dd499)` | 改为主题色变体 |
| metric-icon 蓝 | `linear-gradient(135deg, #3b82f6, #60a5fa)` | `var(--color-primary-soft)` + `var(--color-primary)` |
| metric-icon 红 | `linear-gradient(135deg, var(--color-danger), #f87171)` | `var(--color-danger-soft)` + `var(--color-danger)` |
| metric-icon 绿 | `linear-gradient(135deg, var(--color-success), #4dd499)` | `var(--color-success-soft)` + `var(--color-success)` |
| quick-icon 渐变 | `premium-icon-g1~g10` 各色 | 统一 `var(--color-primary-soft)` |

### 1.2 轮播背景主题化方案

轮播不再使用 3 种硬编码渐变，改为「主题色 + 透明度叠层」方案，确保任何主题下都协调：

```scss
// 3 张轮播统一使用主题色系，仅通过明度/色相微变区分
.carousel-slide--1 {
  background: linear-gradient(135deg, var(--color-primary), var(--color-minor));
}
.carousel-slide--2 {
  background: linear-gradient(135deg, var(--color-minor), var(--color-primary));
}
.carousel-slide--3 {
  background: linear-gradient(135deg, var(--color-primary), var(--color-primary-mist));
}
```

若需保留差异化，可使用 `color-mix` 生成同色系变体：

```scss
.carousel-slide--2 {
  background: linear-gradient(
    135deg,
    color-mix(in srgb, var(--color-primary) 80%, var(--color-success)),
    var(--color-primary)
  );
}
```

> 注：`color-mix` 在 App 端 webview 支持度需验证，降级方案为统一使用主题主色渐变。

### 1.3 深色主题适配

深色主题下需特别注意：

1. **卡片边界**：浅色主题靠阴影区分，深色主题需加边框辅助：
```scss
.tool-card, .recommend-card, .summary-card {
  border: 2rpx solid var(--color-border-light);
}
```
浅色主题下 `--color-border-light` 接近白色，边框不可见；深色主题下自动显现。

2. **半透明白色元素**：Hero 中的 `rgba(255,255,255,0.2)` 在深色主题下仍可使用（因 Hero 本身是主色渐变，与主题深浅无关）。

3. **图标背景**：`--color-primary-soft` 在深色主题下为 `#2a2a50`，主色图标仍能保持对比度。

### 1.4 玻璃拟态降级

底部导航使用 `backdrop-filter: blur(18px)`，在不支持的设备上降级为：

```scss
.nav-shell {
  background: rgba(255, 255, 255, 0.92);
  /* 降级背景 */
  background: var(--color-surface);
}
```

使用 `@supports` 检测能力：

```scss
@supports (backdrop-filter: blur(18px)) {
  .nav-shell {
    background: rgba(255, 255, 255, 0.92);
    backdrop-filter: blur(18px);
  }
}
```

## 二、动效规范

### 2.1 入场动效

页面加载时区块依次淡入上移，营造节奏感。

**触发时机**：`onShow` 数据加载完成后。

**参数**：

| 参数 | 值 |
|------|-----|
| 位移 | `20rpx` → `0` |
| 透明度 | `0` → `1` |
| 时长 | `400ms` |
| 缓动 | `cubic-bezier(0.22, 1, 0.36, 1)` |
| 错峰间隔 | `80ms` |

**实现方式**（保留现有 `premium-fade-in` 机制，统一参数）：

```scss
.premium-fade-in {
  opacity: 0;
  transform: translateY(20rpx);
  animation: premiumFadeIn 0.4s cubic-bezier(0.22, 1, 0.36, 1) forwards;
}

.premium-d1 { animation-delay: 0.08s; }
.premium-d2 { animation-delay: 0.16s; }
.premium-d3 { animation-delay: 0.24s; }

@keyframes premiumFadeIn {
  to {
    opacity: 1;
    transform: translateY(0);
  }
}
```

**错峰分配**：

| 区块 | 延迟类 |
|------|--------|
| Hero | 无（立即显示） |
| 概要卡片 | 无 |
| 搜索+公告 | `premium-d1` |
| 快捷宫格 | `premium-d2` |
| 轮播 | `premium-d3` |
| 推荐/工具 | `premium-d3` |

### 2.2 点击反馈

所有可点击元素统一：

```scss
.tappable {
  transition: transform 0.15s ease, opacity 0.15s ease;
}
.tappable:active {
  transform: scale(0.97);
  opacity: 0.85;
}
```

### 2.3 轮播动效

| 参数 | 优化前 | 优化后 |
|------|--------|--------|
| 自动播放间隔 | `3500ms` | `5000ms` |
| 滑动时长 | 默认 | `500ms` |
| 指示点切换 | `width` 过渡 | 保留 |

### 2.4 公告滚动

| 参数 | 优化前 | 优化后 |
|------|--------|--------|
| 自动播放间隔 | `3200ms` | `4000ms` |
| 方向 | 垂直 | 垂直（保留） |

### 2.5 标语轮播

Hero 副标题的标语轮播保持现有逻辑（`sloganTimer` 5s 切换），但增加淡入淡出：

```scss
.hero-sub {
  transition: opacity 0.3s ease;
}
```

切换时短暂降低透明度再恢复，避免文字跳变。

## 三、无障碍与性能

### 3.1 对比度校验

| 元素组合 | 浅色主题 | 深色主题 | 是否达标 |
|----------|----------|----------|----------|
| 主文字 / 表面色 | `#0b0b12` / `#fff` = 18:1 | `#eeeef0` / `#1a1a26` = 14:1 | ✅ |
| 次文字 / 表面色 | `#6f7180` / `#fff` = 5.2:1 | `#9a9ab0` / `#1a1a26` = 7:1 | ✅ |
| 三级文字 / 表面色 | `#a5a7b5` / `#fff` = 2.8:1 | `#6a6a80` / `#1a1a26` = 3.5:1 | ⚠️ 仅用于装饰 |
| 主色 / 主色浅底 | `#5b5bd6` / `#f0efff` = 4.8:1 | `#6b6be0` / `#2a2a50` = 4.2:1 | ✅ |

> 三级文字仅用于标签与辅助说明，不作为正文，对比度放宽至 3:1 以上即可。

### 3.2 性能约束

- 首页 CSS 动画仅使用 `transform` 与 `opacity`，不触发重排。
- 轮播 `swiper` 使用原生组件，不自定义 JS 动画。
- 入场动画仅在首次加载播放，`onShow` 重复触发时不重播（通过 `v-if` 或标志位控制）。
- 图标使用 SVG 内联或本地图片，避免网络请求。
