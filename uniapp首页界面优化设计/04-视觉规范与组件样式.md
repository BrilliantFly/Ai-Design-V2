## 一、色彩规范

### 1.1 色彩角色定义

首页仅使用以下色彩角色，禁止新增硬编码色值：

| 角色 | 变量 | 用途 |
|------|------|------|
| 主色 | `--color-primary` | Hero 渐变、主操作、图标主色 |
| 主色浅 | `--color-primary-soft` | 图标背景、标签背景 |
| 主色薄雾 | `--color-primary-mist` | 区块背景点缀 |
| 辅助色 | `--color-minor` | Hero 渐变第二色 |
| 成功色 | `--color-success` | 在线状态、完成进度 |
| 警告色 | `--color-warning` | 待办、提醒 |
| 危险色 | `--color-danger` | 告警、badge |
| 成功浅 | `--color-success-soft` | 成功图标背景 |
| 警告浅 | `--color-warning-soft` | 警告图标背景 |
| 危险浅 | `--color-danger-soft` | 危险图标背景 |
| 表面色 | `--color-surface` | 卡片背景 |
| 表面软色 | `--color-surface-soft` | 容器、次级背景 |
| 主文字 | `--color-text` | 标题、正文 |
| 次文字 | `--color-text-secondary` | 描述、说明 |
| 三级文字 | `--color-text-tertiary` | 标签、辅助 |
| 边框 | `--color-border-light` | 分隔线 |

### 1.2 禁止使用的色值

以下硬编码色值需全部替换为主题变量：

| 原硬编码值 | 替换为 |
|-----------|--------|
| `#6366f1` | `--color-primary` |
| `#8b5cf6` | `--color-minor` |
| `#22b573` | `--color-success` |
| `#4dd499` | `--color-success` 浅化 |
| `#e85a5a` | `--color-danger` |
| `#f0a020` | `--color-warning` |
| `#d4956b` | `--color-primary`（暖主题自动适配） |

## 二、排版规范

### 2.1 字体层级 Scale

| 层级 | 字号 | 字重 | 行高 | 用途 |
|------|------|------|------|------|
| Display | `36rpx` | 700 | 1.2 | Hero 问候语 |
| H1 | `32rpx` | 700 | 1.2 | 概要大数字 |
| H2 | `28rpx` | 600 | 1.3 | 区块标题 |
| H3 | `24rpx` | 600 | 1.3 | 卡片标题 |
| Body | `22rpx` | 400 | 1.5 | 正文、描述 |
| Caption | `18rpx` | 400 | 1.4 | 标签、辅助文字 |

### 2.2 字重使用规则

- `700`：仅用于主标题与数字，不超过 2 处/屏。
- `600`：用于区块标题与卡片标题。
- `400`：正文与辅助文字。
- 不使用 `500`（与 400/600 差距过小）。

## 四、点击反馈规范

所有可点击元素统一使用以下反馈：

```scss
.tappable:active {
  transform: scale(0.97);
  opacity: 0.85;
  transition: all 0.15s ease;
}
```

- 缩放比例统一 `0.97`（淘汰 `var(--scale-active)` 分散定义）。
- 时长统一 `150ms`，缓动 `ease`。
- 禁用 `:hover` 态（移动端无 hover）。
