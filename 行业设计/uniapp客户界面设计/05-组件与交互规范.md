## 2. 配置驱动（对齐 PC 端 sections.ts）

- 新建 `src/config/customer-sections.ts`：从 PC 端 `sections.ts` 转录一份**平台无关的区域树配置**（结构同 `SectionDef`：`title / defaultOpen / subSections[].title / fields[{label,key,type,options,placeholder}]`）。
- 表单页与详情页共用该配置渲染，**单份维护**（PC 端 / uniapp 端各持一份；后续可考虑抽包共享，本期不做）。
- `type` 扩展移动端枚举：`input / number / textarea / select / selectMultiple / date`；PC 端既有 `selectMultiple` 语义兼容。

## 3. 交互规范（历史约束落地表）

| 历史约束（PC 端） | uniapp 落地 |
|-------------------|-------------|
| 表单/详情弹窗要有"全屏"按钮 | 移动端表单为**整页**，无弹窗需求；详情页**区段折叠** + 页面滚动控制高度；**跟进方式选择、行业选择、筛选面板**等底部弹层为半屏（≤ 70vh），内容多时弹层内可滚动 |
| 弹窗确定/取消用中文 | 所有弹层按钮一律中文：`确定`/`取消`/`保存`/`重试`/`重置`；不使用 OK/Cancel |
| placeholder 含括号及内容 | 全部沿用 PC 端 placeholder 文案，如：`请选择赚钱方式(可多选)`、`请描述性格特点(如外向健谈、谨慎务实)`、`多个标签用逗号分隔` |
| input/textarea 宽度与右边缘齐平、随全屏变长 | 控件通栏：`width: calc(100% - 32rpx 边距)`，不限制单行长度，textarea 高度 `min-height 160rpx` 可拖拽/自动增高 |
| 详情除非全屏，合理固定高度 | 详情区段卡片化折叠；头部卡片固定，区段按需展开 |
| 操作栏文字不换行 | 列表卡片操作区（编辑/详情等）单行排布，文字 ≤ 4 字，`white-space: nowrap` |

## 4. 通用交互细则

### 4.1 底部弹层（uni-popup bottom 模式）

- 容器：圆角 24rpx 顶、局部阴影、最大高度 70vh，内容区滚动。
- 示例：筛选面板、IndustryPicker、跟进方式选择。
- 关闭：点遮罩/取消/确定后关闭；确定执行操作并 toast。

### 4.2 表单容器

- `uni-forms` + `uni-forms-item`（label 通栏顶部对齐或左侧 160rpx 对齐，全项目统一左侧对齐）。
- 校验：`rules` 驱动；`validate` 失败定位到错误项并 toast 首条错误信息。
- 保存按钮：固定底部操作栏（安全区 padding 适配刘海屏），loading 态防重复。

### 4.3 列表分页

- 统一 `z-paging`（项目已引入）：`ref` 注入、`:refresher-enabled`、`@query` 回调内调 page 接口、`v-model` 数据绑定；空数据用插槽空态。
- 统计卡不做分页，独立 `onShow` 刷新。

### 4.4 状态与空/错态

| 场景 | 组件 | 文案 |
|------|------|------|
| 空列表 | EmptyState | "暂无客户数据" + [新增客户] |
| 接口失败 | PageStatus | "客户数据加载失败" + [重试] |
| 详情无企业 | 内联提示 | "未关联企业" |
| 跟进为空 | 内联提示 | "暂无跟进记录，点击右上角添加" |

### 4.5 主题与样式（欢迎语视觉基准）

> 视觉基准采样首页「欢迎语」：`src/pages/index/index.vue` `.hero-bar` / `.hero-welcome` 系列样式与 `src/pages/plan/home/index.vue` Hero Bar（同款，单位 px 版本）。

#### (1) 主题变量体系（唯一色值来源）

| 语义 | 变量 | 说明 |
|------|------|------|
| 页面背景 | `--color-bg-app` / `--color-bg` | 页面容器 / 内容区底色 |
| 卡片面 | `--color-surface` / `--color-surface-soft` / `--color-surface-hover` | 卡片面 / 次级面 / 按压态 |
| 文字 | `--color-text` / `--color-text-secondary` / `--color-text-tertiary` | 主 / 次 / 弱 |
| 边框 | `--color-border` / `--color-border-light` / `--color-border-hover` | 常态 / 轻 / 悬停 |
| 主色系 | `--color-primary` (+`--color-primary-rgb`) / `--color-primary-soft` / `--color-primary-mist` / `--color-minor` / `--color-btn-text` | 渐变页头与主按钮 |
| 状态色 | `--color-success-soft` / `--color-warning-soft` / `--color-danger-soft` / `--color-danger-rgb` | Tag / 徽标底色 |
| 阴影 | `--shadow-sm` / `--shadow-md` / `--shadow-lg` / `--shadow-glow` | 卡片层级（glass 主题为 `none`） |
| 渐变 | `--gradient-primary` | `linear-gradient(135deg, primary, primary-mist)`，**hero 页头统一用它**（主题内已定义，勿自拼） |

#### (2) 欢迎语 hero 视觉语言（强样式区统一范式）

- **渐变页头**：`background: var(--gradient-primary)`（首页使用 `primary→minor` 双色，主题对抗风险更高，故统一收敛为 `--gradient-primary`），`position: relative; overflow: hidden`。
- **装饰元素**（纯装饰，`pointer-events: none`）：
  - `::before` 右上大圆：`right: -60rpx; top: -60rpx; 260×260rpx; border-radius: 50%; background: rgba(255,255,255,0.06)`；
  - `::after` 左下大圆：`left: -100rpx; bottom: -90rpx; 220×220rpx; background: rgba(255,255,255,0.04)`；
  - `.deco-ring` 圆环：`border: 3rpx solid rgba(255,255,255,0.16)`；
  - `.deco-dot` 点阵：`16rpx` 圆点 + 两枚错位 `box-shadow` 点。
- **渐变区上文字一律 `--color-btn-text`**（macaron/milky/neon 为深色，不假设白色），次级文字用其 `opacity: 0.78` 变体。
- **头像（avatar/首字）**：圆形 `background: rgba(255,255,255,0.2)` + `box-shadow: inset 0 0 0 2rpx rgba(255,255,255,0.14)`（白色毛玻璃边框），文字 `--color-btn-text` 加粗。
- **图标浮层**：`background: rgba(255,255,255,0.16); backdrop-filter: blur(10rpx)`，按压 `transform: scale(var(--scale-active, 0.96))`。
- **状态栏避让**：App 端自定义导航头部 `padding-top: calc(基础值 + var(--status-bar-height))`（`#ifdef APP-PLUS`，参照 `index.vue`）。

#### (3) 主题适配规则（20 套 theme 全覆盖）

1. **禁写死色值**：所有背景/文字/边框/阴影/渐变必须用上面变量表（含 20 主题由 H5 `data-theme` 与小程序/App `themeInlineVars` 双通道统一输出）。
2. **深浅底色可读性以变量做**：文字一律 `--color-text*`，Tag 底色用 `--color-*-soft` + 文字 `--color-primary`/`--color-danger`（danger 徽标文字仍白，见 `plan/home` `.badge`）。
3. **主按钮**：背景 `--color-primary`，文字 `--color-btn-text`（勿写死白）。
4. **卡片**：背景 `--color-surface`，阴影 `--shadow-sm/md`（glass 主题阴影自动为 none，无需特判）。
5. **玻璃拟态**：`backdrop-filter: blur(10rpx)` 仅作增强，底色叠加用 `--color-*-soft`；深色主题（dark/purple/glass/neon）自动获得同构深色卡片。
6. **悬浮阴影/亮点**：可用 `--shadow-glow`（内置 `--color-primary-rgb` 透明光晕），无需手写 rgba 主色。
7. **渐变仅用 `--gradient-primary`**，不在组件内 `linear-gradient` 拼装主题色（主题切换时保证整体换肤一致）。

#### (4) 单位与工程

- 尺寸用 rpx（H5 端 postcss-rem-to-responsive-pixel 自动转换）；渐变/装饰圆参照 `index.vue` rpx 值，`plan/home` px 值仅作视觉比例参照。
- 组件样式 `scoped scss`；客户特有视觉变量不新增，全部复用 `themes.scss` 既有变量。

## 5. 组件接口草案

```typescript
// SectionCard
props: { title: string; open?: boolean; badge?: string }   // emit: 'toggle'
// SubSection
props: { title: string; level?: 2 | 3 }
// FieldItem —— 配置驱动渲染
props: {
    label: string
    key: string
    type: 'input' | 'number' | 'textarea' | 'select' | 'selectMultiple' | 'date'
    options?: { label: string; value: string | number }[]
    placeholder?: string
    modelValue: any          // selectMultiple 为数组
}
// MultiSelectChips
props: { options; modelValue: string[]; placeholder }
// IndustryPicker
props: { modelValue: number[]; show: boolean }   // emit: 'update:modelValue' / 'confirm'
```
