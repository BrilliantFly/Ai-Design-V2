# 02 - 列表页设计（客户列表 / 公司列表）

## 1. 客户列表页 `pages/customer/info`

> 改造现有 `info.vue`：保留统计卡与搜索布局，补数据通道、状态筛选、分页与空/错态。**列表形态 = 纯列表流 + 状态筛选（已确认）**，去掉字母分组 A-Z 索引，统一 z-paging 分页流（数据量成长无上限问题）。

### 1.1 页面结构（线框）

```
┌───────────────────────────────────────┐
│ 客户管理                     [筛]      │  ← navbar（标题"客户管理"）
├───────────────────────────────────────┤
│ 🔍 搜索客户名称/手机号/公司...   [筛选]  │  ← 搜索框（点击展开筛选面板）
├───────────────────────────────────────┤
│ ┌总客户┐ ┌本月新增┐ ┌待跟进┐             │  ← 统计卡（getCustomerStatistics）
│ │ 22  │ │  5   │ │  3  │              │
│ └─────┘ └───────┘ └─────┘             │
├───────────────────────────────────────┤
│ [全部][潜在][有意向][已成交][流失]      │  ← 状态 chips（单选，置顶常驻）
├───────────────────────────────────────┤
│ ◐ 客户头像  张三              [意向]   │  ← 客户卡片（纯列表流）
│             ABC科技  138****8000       │
│ ◐ 李四                    [潜在]      │
│             金融集团  139****1234       │
│                  ↓ 下拉加载更多          │  ← z-paging 分页流
├───────────────────────────────────────┤
│                                (+)     │  ← FAB 新增（悬浮）
│        [工作台][小记][新建][知识库][我的] │  ← PremiumBottomNav
└───────────────────────────────────────┘
```

### 1.2 交互说明

| 元素 | 行为 |
|------|------|
| 搜索输入 | 防抖 300ms，`name/phone/companyName` 模糊匹配（后端 `name`、`phone` 入参）；有输入时显示"清除" |
| 筛选面板 | 点击"筛选"按钮弹出底部面板：客户类型（1 普通/2 重点）、来源、区域；确认/取消**中文按钮** |
| 状态 chips | 单选：全部/潜在(1)/有意向(2)/已成交(3)/流失(4)；选中态高亮，与后端 `status` 参数映射；数据量变化即触发 `z-paging.reload()` |
| 统计卡 | `GET /api/biz/customer/statistics` → total / monthly / following；加载失败显示 `--`，不打断列表 |
| 客户卡片 | 头像取姓名首字母+渐变底色（渐变收敛为 `--gradient-primary`/`--color-primary-soft`）；状态 Tag 色：签=绿/约跟=橙/流失=红/其他=灰；点击 → 详情 |
| FAB "+" | 新增客户 → `form?mode=create` |
| 下拉刷新 | `enablePullDownRefresh` 或 z-paging refresher，重拉第一页 |
| 上拉加载 | z-paging 触底加载 `pageNum/pageSize` |
| 空列表 | 空态插画 + "暂无客户数据" + [新增客户] 按钮（引导建档），区别于接口失败 |

> **视觉规范**（详情见 [05 文档 §4.5](./05-组件与交互规范.md#45-主题与样式欢迎语视觉基准)）：页面背景 `--color-bg-app`；统计卡/客户卡片面 `--color-surface` + `--shadow-sm/md`；状态 chips 未选中 `--color-surface-soft`、选中 `--color-primary` + `--color-btn-text`；头像圆形首字白字（`--color-btn-text`）+ `inset` 光环（参照 hero-avatar），背景 `--gradient-primary`；FAB 背景 `--color-primary`。全量使用主题变量，20 套主题自动换肤。

### 1.3 状态与错误处理

| 状态 | 表现 |
|------|------|
| 加载中 | 骨架屏（列表卡片×3 灰块）或 z-paging 默认 loading |
| 接口失败 | 错误态："客户数据加载失败" + [重试] 按钮（`!isHtmlResponse` 判断去掉，不再静默空态） |
| 未登录 | meta.auth 拦截跳登录 |
| 空数据 | 空态 + 引导新增 |

### 1.4 数据来源

```
GET /api/biz/customer/page?name=&status=&customerType=&source=&regionCode=&pageNum=&pageSize=
  → records: { id, name, gender, phone(脱敏), companyName, status, statusText, sourcesText? }
  → total
```

- 列表字段清单：`id / name / gender / age / phone(脱敏 138****8000) / companyName / status / statusText / customerType / source / createTime`。
- 头像：无头像时取姓名首字符 + 渐变（沿用现逻辑）。

## 2. 公司列表页 `pages/customer/company`（可选，服务于表单企业选择）

```
┌───────────────────────────────────────┐
│ 公司列表                               │
├───────────────────────────────────────┤
│ 🔍 搜索公司名称/行业...                 │
├───────────────────────────────────────┤
│  ABC 信息科技有限公司   互联网/IT        │
│  100-500人 · 企业级 SaaS                │
│  北京智造科技有限公司     智能制造        │
│  50-100人 · 工业软件                    │
│             ↓ 下拉加载更多              │
└───────────────────────────────────────┘
```

- API：`GET /api/biz/customer/company/page?name=&pageNum=&pageSize=`
- 用途：表单"企业情况"区域提供 [选择已有公司] 快捷入口，选中后回填 company 字段并锁住企业名称输入（可解锁改为手动）。
- 交互：`@tap` 行 → `uni.$emit('company:selected', {...})` 或 `eventChannel` 回传；表单页监听回填 `companyId` + company 字段。
