# 04 - 表单页设计（新增 / 编辑客户）

> 页面：`pages/customer/form`，`mode=create | edit` 共用，配置驱动渲染。
> 字段层级**逐字镜像 PC 端** `know-vue/src/views/biz/customer/sections.ts`（字段 key / label / 选项 / 顺序），保证两端数据一致、维护同构。

## 1. 页面结构（线框）

```
┌───────────────────────────────────────┐
│ ← 新增客户 / 编辑客户          [保存]  │  ← navbar 右侧"保存"（中文按钮）
├───────────────────────────────────────┤
│ ▼ 客户个人资料                         │  ← 一级区域卡片（默认展开第一个）
│   ┌ 基础认识 ────────────────────┐    │
│   │ ▸ 基础信息                   │    │  ← 二级区域小节（点击可折叠整区）
│   │   客户姓名   [输入框]         │    │
│   │   性别      [男 ▾]           │    │
│   │   年龄      [输入框]          │    │
│   │   手机号    [输入框]          │    │
│   │   邮箱      [输入框]          │    │
│   │   联系地址  [输入框]          │    │
│   │ ...                          │    │
│   └──────────────────────────────┘    │
│ ▸ 基础情况                             │
│ ▸ 业务情况                             │
│ ▸ 客户企业与行业情况（客户类型=企业时高亮）│
│ ▸ 动态信息 / 价值信息 / 如何把握          │
├───────────────────────────────────────┤
│                     [ 保 存 ]  [取消]  │  ← 底部操作栏（固定）
└───────────────────────────────────────┘
```

- 控件宽度：**通栏（100% - 内边距）**，与右边缘对齐留 32rpx 安全边距；输入控件随内容自动换行、不缩短宽度（历史约束落地）。
- 表单为整页滚动，无固定高度限制；多区域卡片折叠控制视觉密度。

## 1.1 样式规范（欢迎语风格 + 主题适配）

> 页面视觉基准采样首页「欢迎语」hero 体系，完整规范见 [05-组件与交互规范.md §4.5](./05-组件与交互规范.md#45-主题与样式欢迎语视觉基准)。此处记录表单特有落地。

**页头（hero 渐变）**
- 顶部区域：`background: var(--gradient-primary)`，`overflow: hidden`，含 `::before` 右上装饰圆（`rgba(255,255,255,0.06)`，260rpx）与 `.deco-ring/.deco-dot` 装饰；标题「新增客户 / 编辑客户」与右侧 [保存] 按钮文字用 `--color-btn-text`（macaron/milky/neon 主题自动深色），App 端 `padding-top += var(--status-bar-height)`。
- 页面正文背景：`--color-bg-app`；卡片面：`--color-surface` + `--shadow-sm`。

**表单区段卡片**
- 一级区域 = `SectionCard`：圆角 24rpx、背景 `--color-surface`、阴影 `--shadow-sm`；标题文字 `--color-text`（font-weight 600），折叠箭头用 `--color-text-tertiary`。
- 二级小节（`SubSection`）：底色 `--color-surface-soft`（深色主题天然同构），三级字段区为透明背景。
- 卡片默认展开首个一级区域，其余折叠；展开态标题旁主色小竖条或图标用 `--color-primary`。

**表单项**
- label：`--color-text-secondary`，右侧控件值 `--color-text`；placeholder `--color-text-tertiary`。
- 输入控件（easyinput）：背景 `--color-surface-soft`，边框 `--color-border`（聚焦 `--color-primary`），文字 `--color-text`。
- 多选 chips（`MultiSelectChips`）：未选中 `--color-surface-soft` + `--color-text-secondary`；选中 `--color-primary` 背景 + `--color-btn-text` 文字。
- 校验错误态：`--color-danger` 文字 + `--color-danger-soft` 底（勿写死红值）。
- 底部操作栏：背景 `--color-surface` + 顶部 `--color-border` 分隔线；主按钮「保存」背景 `--color-primary`、文字 `--color-btn-text`；次按钮「取消」描边 `--color-border` + 文字 `--color-text-secondary`。

**主题切换验证**：P7 阶段在 H5 切 white→dark→sakura 3 套主题核查：页头渐变、卡片面、label/placeholder 可读性、chips 选中态、错误态自动换肤。

## 3. 提交数据组装

```typescript
interface CustomerSubmit {
    name: string
    gender?: number
    age?: number
    phone?: string
    email?: string
    address?: string
    regionCode?: string
    // 基础认识字段
    appearance?: string
    personality?: string
    lifestyle?: string
    hobby?: string
    occupation?: string
    position?: string
    earningWay?: string          // 数组 join(',')
    socialClass?: string         // 数组 join(',')
    socialCircle?: string
    // 详细认识字段
    maritalStatus?: string
    familySituation?: string
    familyAddress?: string
    education?: string
    valuesText?: string
    basicLifeSkill?: string
    vocationalSkill?: string
    sportsSkill?: string
    artSkill?: string
    techSkill?: string
    // 基础/业务情况
    customerType?: number
    source?: string
    status?: number
    demandLevel?: number
    valueScore?: number
    demandWillingness?: number
    demandBudget?: number
    demandDecision?: string
    demandPriority?: number
    demandTags?: string
    demandDesc?: string
    // 企业+行业+画像
    company?: { name?: string; industry?: string; /* ...见 2.4 */ } // 空串由后端 sanitizeBlankFields 清洗，可整体省略传 null
    industryIds?: number[]
    profile?: { dynamicInfo?: string; valueLevel?: number; valueExpect?: string; valueInterest?: string; strategy?: string; talkScript?: string; analysis?: string }
}
```

- `create` → `POST /api/biz/customer`；`edit` → `PUT /api/biz/customer`（带 id）。
- 提交前处理：`selectMultiple` join；空串字段可置 `''`（后端已清洗为 null，无需前端删字段）；`company` 为空对象时整体不传。

## 4. 回填规则（编辑态）

- `GET /api/biz/customer/{id}` 返回 `{...customer, profile, company, industries, industryIds}`。
- `earningWay / socialClass`：`split(',')` → 数组回填 chips 选中态。
- `company.*`：非空时回填嵌套对象；`profile.*` 同。
- `industryIds`：由 `industries[].industryId` 或响应 `industryIds[]` 直接回填。
- 进入页面参数 `mode=edit&id=` 缺失时 toast 并返回列表。

## 5. 校验规则（uni-forms）

| 字段 | 规则 |
|------|------|
| name | 必填，长度 ≤ 50 |
| phone | 可选；填了则 `/^1\d{10}$/`（提示"手机号格式不正确"） |
| email | 可选；填了则邮箱正则 |
| age | 0-120 |
| demandBudget | ≥ 0，两位小数内 |
| earningWay/socialClass | 非必选；选中即高亮 chip，空值提交 `''` |

- 校验失败：uni-forms `validate` 返回首错，`uni.showToast` 提示 + 自动滚动到该区域。
- 保存中：按钮 loading 防重复提交（useLockFn 已有 hook 可复用）。
