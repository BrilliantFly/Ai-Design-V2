# 客户 / 行业 / 行业产品 / 行业企业 / 行业与市场 —— 表单与详情层级化 + 新增字段设计 V3

> 创建日期：2026-09-12
> 版本：V3.0（在 V2 客户信息调用 + 市场与行业调研设计之上，做**表单/详情层级化重构**与**扩展字段补全**）
> 状态：设计稿（待评审）
> 依据：`行业设计/客户信息调研.xlsx`、`行业设计/市场与行业调研.xlsx` 两个调研表；前端 `src/views/biz/**`、后端 `know-boot-biz` 现有实体

## 1. 背景与问题

### 1.1 现状

调研表内部存在清晰的**层级关系**（如 `上下游产业链` 是区段、其下分 `上游（原材料）/ 中游（产品制造商）/ 下游（销售渠道、营销）`，`下游` 下再分 `渠道 / 营销`），但当前界面是**扁平字段摊开**，层级感丢失：

- 行业表单/详情把 `upstreamChain / midstreamChain / downstreamChannel / downstreamMarketing` 平铺展示，看不出"上下游产业链 → 下游 → 渠道/营销"的归属关系；
- 产品细分（核心/基础/附加/潜在）、商业模式九要素、竞争分析等本应嵌套展示的分组，均以平铺/单行文本呈现；
- **行业产品、行业企业、行业与市场** 三张表缺少 `动态信息 / 价值信息 / 如何把握`（行销分析三件套）；
- **客户** 表单/详情未按"基础信息 → 客户企业与行业情况 → 动态信息 → 价值信息 → 如何把握"分层组织。

### 1.2 设计目标

1. **层级化表单/详情**：界面按"**一级区域 → 二级区域 → 字段**"组织，明确父子归属（示例：`上下游产业链` 占一个区域，其下分 `上游（原材料）/ 中游（产品制造商）/ 下游（销售渠道、营销）` 三个子区域）。
2. **新增字段与功能**：为 客户/行业/行业产品/行业企业/行业与市场 补齐 **动态信息、价值信息（用户称"价值新增"）、如何把握** 三组字段及编辑功能。
3. **兼容现有数据**：既有字段保留原名与位置，仅重组展示分组；新字段全部可空，不影响存量数据。

## 2. 层级模型定义（UI 通用约定）

表单与详情共用同一棵"区域树"，渲染规则统一：

```
Region (一级区域)            —— 卡片标题 + 折叠
├── Region (二级区域)        —— 缩进小节标题
│   ├── Region (三级区域)    —— 等宽小标题（如需）
│   └── Field                —— 表单控件 / 详情描述项
└── Field
```

- **区域**：`sectionTitle`（如 `上下游产业链`）；
- **子区域**：`subSections[]`（如 `上游（原材料）`、`中游（产品制造商）`、`下游（销售渠道、营销）`）；
- **字段**：`label + value`，表单为输入控件，详情为静态展示；
- 一级区域之间的顺序 = 调研表行序（基础信息 → 动态信息 → 价值信息 → 如何把握 → 其他）；
- 表单与详情**同构复用**同一份区域配置（`section.ts` 配置驱动渲染），避免双份维护。

## 6. 前端设计

### 6.1 配置驱动：`src/views/biz/**/sections.ts`

每模块导出一棵**区域树配置**（表单/详情共用）：

```typescript
interface Section {
  title: string            // 一级区域标题，如"上下游产业链"
  field?: string           // 无子区域的直接字段
  subSections?: Section[]  // 二级/三级区域
  fields?: { label: string; key: string; type?: 'input'|'textarea'|'select'|'tags' }[]
}
```

### 6.2 通用组件

- `SectionCard.vue`：一级区域卡片（标题 + 折叠 `v-collapse`/自定义展开）；
- `SubSection.vue`：二级区域小节（缩进 + 分组边框）；
- `FieldItem.vue`：label + 控件（表单）/ 描述（详情）；
- 复用：企业/产品/市场的行业、产品 **M:N 多选**（已实现，保留）。

### 6.3 表单/详情页面结构（以行业为例）

```
[基础信息]  ▾
│ 行业定义与技术 | 产品 | 企业/平台 | 上下游产业链
│   └ 上下游产业链
│     ├ 上游（原材料）        [textarea upstreamChain]
│     ├ 中游（产品制造商）     [textarea midstreamChain]
│     └ 下游（销售渠道、营销）
│         ├ 渠道  [textarea downstreamChannel]
│         └ 营销  [textarea downstreamMarketing]
[动态信息]      ▾ [textarea dynamicInfo]
[价值信息]      ▾ [textarea valueInfo]     ← 价值新增
[行业资源]      ▾ [textarea industryResources]
[如何把握]      ▾ [textarea strategy]
[其他]         ▾ 毛利额/毛利率/净利额/净利率
```

默认展开第一个一级区域；其余折叠可展开（可按模块配置默认全部展开）。
