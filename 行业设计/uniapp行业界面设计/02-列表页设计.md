# 02 - 列表页设计

> 通用：页头 hero（渐变欢迎语视觉）；正文 `z-paging` 滚动；操作栏文字单行 nowrap；空态/错误态按 01 文档约定复用组件。

```
├──────────────────────────────────────────────────────┤

│ │ 人工智能                    [编辑][删除] │  卡片 1     │
│ │ #AI #大模型  代码: AI-01              │             │
│ │ 市场规模 3000亿 · 企业 15 · 产品 8 · 客户 5 │             │
│ └──────────────────────────────────────┘             │

│ │ 市场规模 5000亿 · 企业 12 · 产品 6 · 客户 8 │             │
│ └──────────────────────────────────────┘             │
│ ...更多（z-paging 上拉加载）                          │
└──────────────────────────────────────────────────────┘
```

**交互**：
- 点击卡片 → 行业全景详情（`detail.vue?id=`）。
- 顶部 StatBar 四格：调 `/api/biz/industry/statistics`（industryCount/enterpriseCount/productCount/relationCount）。
- 筛选行：名称/编码关键字 + 标签（多选 chips，复用 MultiSelectChips）+ 查询/重置。
- 操作栏：编辑/删除（删除二次确认 `模态框`，中文按钮）。

**字段展示**：industryName / code / tags（tag-chip）/ scale（市场规模）/ productCount / enterpriseCount / customerCount（统计来自 `{id}/statistics` 侧各聚合或列表行接口）。

## 5. 列表页共性

- 统计无需分页：仅行业列表页有 StatBar，`onShow` 刷新。
- 卡片操作按钮 ≤ 4 字、`white-space: nowrap`、最小热区 88rpx。
- 删除：`uni.showModal`（`确认删除该行业吗？删除后关联产品/企业/市场数据保留但解除关联`）。
- 权限：仅"可编辑"用户显示 编辑/删除/新建（沿用客户模块按钮级权限位）。
