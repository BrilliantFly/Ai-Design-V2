# 03 - 详情页设计

> 详情页统一范式（与客户详情一致）：hero 头卡 + 区段折叠（SectionCard collapsible，默认折叠，首个默认展开）+ 二级分组（SubSection）+ 字段行（FieldItem）+ 底部固定操作栏（编辑/删除）。

### 1.1 四 Tab 切换

- `IndustryTabs`：`uni-segmented-control`（吸顶 sticky，`background: var(--color-bg)`）；四 tab 内容懒加载 `v-if` 首次进入后 `v-show` 保留状态。
- 深链参数 `?id=xxx&tab=market`（客户详情行业标签跳转带 `tab=market`）。

### 1.2 全景 Tab 区段结构（折叠状态按设计：全部默认折叠，首段"行业定义与技术"默认展开）

| 区段 | 内容（字段见 06 文档） | 默认 |
|------|------------------------|------|
| 1. 行业定义与技术 | 名称/代码/标签/可见性/排序；行业定义；核心技术 | 展开 |
| 2. 上下游产业链 | ChainView：上/中/下游各含 `名称+渠道`，下游另含 `营销方式` | 折叠 |
| 3. 行业发展概况 | 概述 / 市场规模 / 增长潜力（低/中/高渲染等级） | 折叠 |
| 4. 财务指标 | FinancePanel：毛利额/毛利率/净利额/净利率（金额格式化 亿/万） | 折叠 |
| 5. 动态信息 | 行业动态时间线（FollowupTimeline 复用，内部字段 新增动态） | 折叠 |
| 6. 价值信息 | 行业价值/价值提升点 | 折叠 |
| 7. 行业资源 | 专家资源/渠道资源/案例库 | 折叠 |
| 8. 如何把握 | 把握策略/行动方案 | 折叠 |

### 1.3 客户分布（行业 ⇄ 客户多对多）

```
┌ Tab 外挂或全景底部：行业拥有的客户 ───────────────┐
│ 客户 5 位                    [关联客户▾]           │
│ ┌────────────────────────────────┐             │
│ │ 张三 · 个人 · 意向 · 主营行业(主营) │  → 客户详情   │
│ │ 王五 · 企业 · 成交 · 关联行业      │             │
│ └────────────────────────────────┘             │
└──────────────────────────────────────────┘
[关联客户] → uni-popup 底部弹层（≤70vh）：
   搜索+多选（调 customer 子域列表）→ 已选 n 项 → [确定]
   提交 POST /api/biz/industry/{id}/customers {customerIds:[...]}
```

- 关系类型渲染：主营行业（回显 tag `--color-primary-soft`）/ 关联行业（`--color-surface-soft`）。
- 点击客户行 → 客户详情（`/pages/customer/detail?id=`，与客户模块互通）。

## 5. 详情页共性

- 一级区段 SectionCard、二级分组 SubSection（如"基础信息"内"企业平台/工商信息"）、三级 `.sub-heading`（如"上游/中游/下游"）。
- 空值一律 `--`（FieldItem emptyText）；多值（标签/渠道）用 tag-chip；长文本 2 行省略 + 可展开全文（点击字段展开/收起）。
- 数值格式化：金额 `亿` 级（`>=1e8 → x.xx亿`，`>=1e4 → x.x万`），百分比加 `%`。
- 底部操作栏：编辑（进表单）/删除（确认模态框），无编辑权限隐藏。
