## 2. 新增组件接口草案

```typescript
// StatBar
props: { items: { label: string; value: number; key: string }[] }   // key 用于 onShow 刷新后局部更新
// IndustryTabs
props: { tabs: { key: string; label: string }[]; active: string }   // emit: 'change'
// ChainView
props: { upstream: { name[]; channel[] }; midstream: {...}; downstream: { name[]; channel[]; marketing[] } }
       // 每段：标题 + 展开/收起；无数据渲染 "暂无上游环节"
// BusinessModelGrid
props: { cells: { key: string; label: string; value?: string }[] }  // 9 格 + 底部 costStructure 专属格
// FinancePanel
props: { grossProfit; grossMargin; netProfit; netMargin }           // 内部 formatMoney + %
// CustomerDistPanel
props: { industryId: number; count: number }                        // emit: 'linked'
```

## 3. 视觉基准（欢迎语 hero 语言，强样式区统一范式）

- **页头 hero**：`background: var(--gradient-primary)`；`::before` 右上大圆（260×260rpx，`rgba(255,255,255,0.06)`）、`::after` 左下大圆（220×220rpx，`0.04`）；`pointer-events: none`。
- **页头文字**：主标题 `--color-btn-text` 加粗；次级 `opacity: 0.78` 变体。
- **主题适配**：
  1. 禁写死色值，一律 `--color-*` 变量（20 主题 H5 `data-theme` / 小程序 `themeInlineVars` 双通道）。
  2. 卡片 `--color-surface` + `--shadow-sm/md`（glass 主题自动 none）。
  3. 主按钮 `--color-primary` + 文字 `--color-btn-text`。
  4. 渐变仅 `--gradient-primary`，组件内不拼 `linear-gradient`。
  5. Tag 底色 `--color-*-soft` + 文字 `--color-primary`/`--color-danger`（danger 徽标文字白）。
- **单位**：rpx；组件 `scoped scss`。

## 4. 交互细则

### 4.1 底部弹层（uni-popup bottom）
- 关联客户 / 行业（多）选择 / 筛选面板：圆角 24rpx 顶、最大高度 70vh、内容区滚动；按钮中文（确定/取消/重置）；确定执行后 toast。

### 4.2 区段折叠
- SectionCard `collapsible`：全景各 Tab 内容默认折叠（首个"行业定义与技术"展开）；点击标题切换，swiper/segment 切换保留各 Tab 折叠现场。

### 4.3 列表与分页
- `z-paging`：`@query` 调 page 接口、`:refresher-enabled`、空态插槽；删除后 `reload`。
- StatBar 统计独立 `onShow` 刷新。

### 4.4 状态与文案
| 场景 | 组件 | 文案 |
|------|------|------|
| 行业空列表 | EmptyState | "暂无行业数据" + [新建行业] |
| 企业/产品/市场空 | EmptyState | "暂无企业数据" / "暂无产品数据" / "暂无市场数据" |
| 接口失败 | PageStatus | "行业数据加载失败" + [重试]（各域替换名词） |
| 详情无产业链 | 内联 | "暂无产业链数据，点击[编辑]补充" |
| 客户分布为空 | 内联 | "暂无关联客户" + [关联客户] |

### 4.5 中文按钮
所有弹层/模态按钮一律中文（确定/取消/保存/删除/重置/重试/新建），不使用 OK/Cancel。

## 5. 空值/格式化约定
- 空字段：`FieldItem.emptyText` 默认 `--`。
- 金额：`>=1e8 → x.xx亿`；`>=1e4 → x.x万`；<1e4 原值。
- 长文本：详情字段 2 行省略 + 点击展开全文；卡片摘要单行省略。
- 多值字段（标签/渠道/营销）：`splitTags`（逗号/顿号分隔→tag-chip，chip 底色 `--color-primary-soft` 文字 `--color-primary`）。
