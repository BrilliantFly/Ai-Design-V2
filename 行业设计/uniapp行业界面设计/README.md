## 总览（一图流）

```
后台动态菜单下发
└─ 行业调研（父菜单，type=2 目录）
   ├─ 行业列表      → 行业列表 → 点击卡片
   │                            └─ 行业全景详情（四 Tab：全景 / 产品 / 企业 / 市场）
   │                                        ├─ 全景：定义/技术/产业链三段/发展概况/财务指标/动态/价值/资源/如何把握
   │                                        ├─ 产品：产品列表 → 产品详情 / 新增编辑
   │                                        ├─ 企业：企业列表 → 企业详情 / 新增编辑
   │                                        └─ 市场：市场详情 / 新增编辑（商业模式九宫格）
   └─ 行业企业      → 企业列表 → 企业详情 / 新增编辑
   └─ 行业产品      → 产品列表 → 产品详情 / 新增编辑
   └─ 行业市场      → 市场列表 → 市场详情 / 新增编辑

客户详情 → 行业标签（tag-chip）→ 点击跳行业全景详情（tab=市场）
```

## 视觉基准（与客户模块完全一致）

- **页头 hero**：`background: var(--gradient-primary)`；装饰圆 `::before / ::after`（`rgba(255,255,255,0.06) / 0.04`）；页头文字 `--color-btn-text`，次级文字 `opacity: 0.78`；状态栏避让 `padding-top: calc(基础值 + var(--status-bar-height))`（`#ifdef APP-PLUS`）。
- **主题**：20 套主题全覆盖；禁写死色值，一律 `--color-*` 变量；渐变仅用 `--gradient-primary`；主按钮 `--color-primary` + `--color-btn-text`。
- **卡片**：`--color-surface` + `--shadow-sm/md`；区段折叠复用 `SectionCard（collapsible）`，二级分组复用 `SubSection`，字段行复用 `FieldItem`。
- **底部弹层**：`uni-popup` bottom 模式，圆角 24rpx，最大高度 70vh；按钮中文（确定/取消/保存）。
- **列表分页**：`z-paging`；**表单**：`uni-forms` 整页 + 固定底部保存栏 + `useLockFn` 防重复。
- **菜单**：后台动态菜单下发即可显示；**底部 tab 不配置**。
