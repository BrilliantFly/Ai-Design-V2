## 2. 前端 API 文件（新增）

`src/api/biz/industry/index.ts`（行业）+ `product.ts` / `enterprise.ts` / `market.ts`，沿用 `request` 封装（同 customer 模块风格，`method/path/data` 对象式）。示例：

```typescript
import request from '@/utils/request'
export function getIndustryPage(params) { return request.get({ url: '/biz/industry/page', data: params }) }
export function getIndustryList()      { return request.get({ url: '/biz/industry/list' }) }
export function getIndustryDetail(id)  { return request.get({ url: `/biz/industry/${id}` }) }
export function createIndustry(data)   { return request.post({ url: '/biz/industry', data }) }
export function updateIndustry(data)   { return request.put({ url: '/biz/industry', data }) }
export function deleteIndustry(id)     { return request.delete({ url: `/biz/industry/${id}` }) }
export function getIndustryCustomers(id, params) { return request.get({ url: `/biz/industry/${id}/customers`, data: params }) }
export function linkIndustryCustomers(id, data)  { return request.post({ url: `/biz/industry/${id}/customers`, data }) }
export function getIndustryStatistics() { return request.get({ url: '/biz/industry/statistics' }) }
// product / enterprise / market 同构（list / detail / create / update / remove）
```

## 3. 字段树（数据模型，对齐 PC 端 sections.ts）

### 3.1 行业 Industry（表 `biz_industry`）
```
基础信息: industryName / code / tags(逗号分隔) / visible / sort
行业定义: definition / technology
产业链:   upstream(name,channel) / midstream(name,channel) / downstream(name,channel,marketing)
发展概况: overview / marketScale / growthPotential(低|中|高)
财务指标: grossProfit / grossMargin / netProfit / netMargin
动态信息: dynamicInfo / (动态时间线子集)
价值信息: valueInfo / valueImprove
行业资源: expertResource / channelResource / caseLibrary
如何把握: strategy / actionPlan
```

### 3.2 行业企业 Enterprise（表 `biz_industry_enterprise`）
```
企业平台: industryId / productIds(关联产品多选) / enterpriseType(平台|厂商|服务商|集成商) / enterpriseName
工商信息: establishDate / registeredCapital(万) / paidInCapital / scale(<100|100-500|500-1000|1000+|10000+) / listed(是|否) / creditCode
经营与技术: mainBusiness / coreTechnology / marketPerformance
竞争:     competitor / advantage / weakness
产业链:   upstream(name,channel) / midstream / downstream(同行业)
动态/价值信息/如何把握: dynamicInfo / valueInfo / strategy（对齐行业）
```

### 3.3 行业产品 Product（表 `biz_industry_product`）
```
产品分类: industryId / productName / productCode / productTags
产品概念: category(核心|基础|附加|潜在) / concept
消费者洞察: consumerProfile / consumerScene / consumerFrequency
产品细节: productFunction / productForm / priceRange
生命周期: lifeCycle(引入|成长|成熟|衰退) / growthStrategy / declineResponse
价值信息: valueAdd
如何把握: strategy
```

### 3.4 行业市场 Market（表 `biz_industry_market`）
```
基础信息: industryId / demand / opportunity
商业模式九要素: valueProposition / customerSegment / channel / customerRelation /
               revenueSource / keyResource / keyPartner / keyActivity / costStructure
价值评估: valueAssessment / competitionMethod
推广获客: promotionChannel / acquisitionMethod
财务指标: grossProfit / grossMargin / netProfit / netMargin（同行业）
```

## 4. 行业 ⇄ 客户多对多（`biz_customer_industry`）

```
表: bizer_customer_industry (industry_id, customer_id, relation_type 主营行业|关联行业, remark)
行业侧入口: 行业全景 → 客户分布 Tab → [关联客户] → POST /api/biz/industry/{id}/customers
客户侧入口: 客户编辑 → 行业多选(IndustryPicker) → setCustomerIndustries(customerId, {...})
双向同表，任何一侧修改另一侧实时可见（客户详情行业标签 → 跳行业全景 tab=market）
```

## 5. 数据流约定

- 列表统计数（产品/企业/客户）行级由列表接口返回聚合值；StatBar 用 `/statistics`。
- 市场为行业 1:1 附属（`market/{industryId}`）；企业/产品为 N:1（list 按 industryId 过滤）。
- 删除行业：先检查关联（产品/企业/客户），>0 时二次确认提示"将解除 N 条关联"；删除后子表数据保留、industry_id 置空。
