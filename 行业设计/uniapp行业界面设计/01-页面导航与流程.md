# 01 - 页面导航与流程

## 1. 菜单入口（后台动态菜单）

菜单由后台动态下发（沿用客户模块既有菜单消费逻辑），本期**不配置底部 tab**，行业模块作为一级/二级菜单挂在抽屉/我的页面菜单列表：

| 菜单名 | 类型 | 路由路径（前端 pages/industry/...） | 备注 |
|--------|------|--------------------------------------|------|
| 行业调研 | 目录（type=2） | - | 父级，不挂页面 |
| 行业列表 | 页面（type=1） | `/pages/industry/list` | 进入行业列表 |
| 行业企业 | 页面（type=1） | `/pages/industry/enterprise-list` | 全部企业列表 |
| 行业产品 | 页面（type=1） | `/pages/industry/product-list` | 全部产品列表 |
| 行业市场 | 页面（type=1） | `/pages/industry/market-list` | 全部市场列表 |

> 菜单数据源字段沿用既有 `MenuTree`：`id / parentId / name / type / path / sort / visible / icon`；后端返回树后按 type 过滤渲染。

## 2. 页面路由表

```
pages/industry/
├── list.vue                 # 行业列表（统计卡 + 行业卡片列表 + 新建）
├── detail.vue               # 行业全景详情（四 Tab：全景 / 产品 / 企业 / 市场）
├── enterprise-list.vue      # 行业企业列表（全量）
├── product-list.vue         # 行业产品列表（全量）
├── market-list.vue          # 行业市场列表（全量）
├── enterprise-form.vue      # 企业 新增/编辑（整页表单）
├── product-form.vue         # 产品 新增/编辑（整页表单）
├── market-form.vue          # 市场 新增/编辑（整页表单）
└── components/
    ├── IndustryTabs.vue       # 全景详情四 Tab 外壳（swiper/segment）
    ├── ChainView.vue          # 产业链三段视图（上游/中游/下游）
    ├── BusinessModelGrid.vue  # 商业模式九宫格
    ├── FinancePanel.vue       # 财务指标卡（毛利/毛利率/净利/净利率）
    ├── CustomerDistPanel.vue  # 客户分布面板（行业拥有的客户 + 关联弹层）
    └── StatBar.vue            # 列表页顶部统计卡行（行业/企业/产品/客户）
```

## 3. 核心流程

### 3.1 行业主链路

```
行业列表(list.vue)
  ├─ 点击行业卡片 → 行业全景详情(detail.vue?id=xxx)
  │     ├─ Tab1 全景：基础信息（定义/技术/产业链/发展概况）→ 折叠区段
  │     ├─ Tab1 全景：财务指标 / 动态 / 价值 / 资源 / 如何把握 → 折叠区段
  │     ├─ Tab2 产品：产品列表 → 产品详情(数据同屏展开 or 独立) / 新增编辑(product-form.vue)
  │     ├─ Tab3 企业：企业列表 → 企业详情 / 新增编辑(enterprise-form.vue)
  │     ├─ Tab4 市场：市场详情 / 新增编辑(market-form.vue)
  │     └─ 客户分布：行业拥有的客户列表 + [关联客户] 底部弹层勾选
  ├─ 右上角[新建行业] → 行业整页表单（表单弹层 + 保存）
  └─ 顶部统计卡 → 调 /api/biz/industry/statistics（行业/企业/产品/客户总数）
```

### 3.2 独立列表链路（企业/产品/市场）

```
enterprise-list.vue / product-list.vue / market-list.vue
  ├─ 搜索 + 筛选（所属行业、生命周期等）
  ├─ 行操作：详情 / 编辑 / 删除（nowrap 不换行）
  ├─ 右上角[新建] → 对应整页表单
  └─ 详情 → 独立详情视图（区段折叠，字段同 03 文档）
```

### 3.3 双向联动（行业 ⇄ 客户）

```
行业侧：行业全景详情 → 客户分布 Tab → [关联客户] 弹层（调客户子域列表）→ 勾选 → 保存
                                              POST /api/biz/industry/{id}/customers（写 biz_customer_industry）
客户侧：客户详情 → 行业标签（tag-chip）→ 点击 → 跳转行业全景详情（tab=市场）
        客户编辑 → 行业多选（IndustryPicker 底部弹层，复用 getAllIndustries()）
```

## 4. 加载与异常

- 列表：`z-paging` 首屏骨架 + 空态（EmptyState "暂无行业数据" + [新建行业]）/ 错误态（PageStatus "行业数据加载失败" + [重试]）。
- 详情：区段数据一次接口返回（`/api/biz/industry/{id}` 聚合），本地折叠不重复请求；子列表（产品/企业/客户）独立按需加载，失败只 toast 当前 Tab。
- 保存：`useLockFn` 防重复提交；失败 toast 服务端 message，表单保留已填值。
