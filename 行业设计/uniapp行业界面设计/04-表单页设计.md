# 04 - 表单页设计

> 统一范式（与客户模块表单一致）：**整页表单**（无弹窗），hero 页头 + `uni-forms` 配置驱动渲染 + 固定底部保存栏；placeholder 含括号及内容；控件通栏（`width: calc(100% - 32rpx 边距)`）；多选用 chips；行业/生命周期/类型等用 `uni-data-select` 或底部弹层选择器；保存按钮 loading 防重复（useLockFn）。

## 1. 表单结构（配置驱动）

- 新建 `src/config/industry-sections.ts`（行业）/ `enterprise-sections.ts` / `product-sections.ts` / `market-sections.ts`：从 PC 端同名 sections.ts 转录**平台无关区域树**（`SectionDef`：`title / subSections[].title / fields[{label,key,type,options,placeholder,required}]`）。
- type 枚举：`input / number / textarea / select / selectMultiple / date`。
- 表单页与详情页共享该配置（详情只读、表单可写）。
- 校验：`rules` 驱动（required/长度），`validate` 失败 toast 首条并定位。

## 6. 表单交互细则

- 保存：底部固定操作栏（安全区 padding），[保存] 主按钮；成功后 toast "保存成功" 并 `navigateBack`。
- 编辑回显：`onLoad` 按 id 取详情填充；`edit` 模式下顶部 hero 显示"[编辑] 行业名称"态，新建显示"[新建] 行业"。
- 手机号/金额类键盘：number 字段 `type="digit"`。
- placeholder 一律含括号及内容（对齐既有约束）；textarea `min-height: 160rpx` 自动增高。
- 删除权限只读用户：隐藏编辑/新建入口（按钮级权限位，沿用客户模块）。
