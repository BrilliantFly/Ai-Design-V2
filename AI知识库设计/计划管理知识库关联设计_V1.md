# 计划管理知识库关联设计 V1

## 1. 需求
“计划管理、行业列表、行业企业、行业产品、行业市场都可以连接知识库，比如行业链接到知识库，点击行业链接的知识库，可以查看知识库的详细内容”  
（计划管理部分：计划信息/日程/习惯等可连接知识库）

## 2. 设计原则
- 单一外键 `knowledge_base_id`，关联 `kb_knowledge_base.id`
- 向后兼容（NULL）
- 不新增中间表

## 3. 数据库设计

### 3.1 建议新增字段的表

按现有实体梳理，优先级建议：

| 表名 | 实体类 | 业务说明 |
|---|---|---|
| `plan_info` | `PlanInfo` | 计划信息（主实体） |
| `plan_info_template` | `PlanInfoTemplate` | 计划模板（可选：模板预设知识库） |
| `plan_habit` | `PlanHabit` | 习惯（可选） |
| `plan_schedule_event` | `PlanScheduleEvent` | 日程事件（可选） |

**V1 建议：仅在 `plan_info` 新增 `knowledge_base_id`**，满足“计划管理连接知识库”核心诉求，后续按需扩展。

### 3.2 SQL 补丁（V1）

```sql
ALTER TABLE `plan_info`
  ADD COLUMN `knowledge_base_id` BIGINT DEFAULT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）',
  ADD KEY `idx_plan_info_kb_id` (`knowledge_base_id`);

-- 可选（按需启用）
-- ALTER TABLE `plan_info_template`
--   ADD COLUMN `knowledge_base_id` BIGINT DEFAULT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）',
--   ADD KEY `idx_plan_info_template_kb_id` (`knowledge_base_id`);
```

## 4. 后端设计

### 4.1 Entity
```java
@ApiModelProperty("关联知识库ID")
@TableField("knowledge_base_id")
private Long knowledgeBaseId;
```

### 4.2 API
现有 `PlanInfoController`（`/api/plan/info`）的 CRUD 已支持该字段（Jackson 映射），无需新增接口。

## 5. 前端设计

### 5.1 Vue 管理端（`views/plan/info/index.vue`）
- 列表/表单：新增“关联知识库”选择器（可选、可清空）
- 列表列：显示知识库名称
- 操作：当有值时显示“查看知识库”按钮，跳转至知识库文档列表页（`/knowledge/document?knowledgeBaseId=xxx`）

### 5.2 UniApp（`pages/plan/*`）
计划详情页（如 `plan/info/detail.vue` 或 `schedule/detail.vue`）根据实际页面结构，新增“关联知识库”展示与“查看知识库”跳转。

## 6. 验证要点
- 保存/读取正常
- 跳转参数正确
- 字段 NULL 不影响现有计划数据
