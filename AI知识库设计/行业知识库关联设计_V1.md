# 行业知识库关联设计 V1

## 1. 需求
将“行业列表/行业企业/行业产品/行业市场”都可以连接知识库（行业链接到知识库，点击后可查看知识库的详细内容）。

## 2. 设计原则
- 沿用 `kb_` 前缀和现有知识库结构（`kb_knowledge_base` → `kb_directory` → `kb_document`）
- 采用**单一外键**方式：直接在业务实体增加 `knowledge_base_id`（关联 `kb_knowledge_base.id`），不新增中间表
- 向后兼容：字段允许 NULL，默认不关联
- 幂等：SQL 使用 `ON DUPLICATE KEY UPDATE` 或 `ALTER TABLE ADD COLUMN IF NOT EXISTS`（按现有项目习惯处理）

## 3. 数据库设计

### 3.1 字段新增

在以下表新增 `knowledge_base_id` BIGINT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）'：

| 表名 | 实体类 | 备注 |
|---|---|---|
| `biz_industry` | `BizIndustry` | 行业主体 |
| `biz_industry_product` | `BizIndustryProduct` | 行业产品 |
| `biz_industry_enterprise` | `BizIndustryEnterprise` | 行业企业 |
| `biz_industry_market` | `BizIndustryMarket` | 行业市场 |

索引建议（按需）：`KEY idx_knowledge_base_id (knowledge_base_id)`

### 3.2 SQL 补丁

```sql
-- 行业-知识库关联
ALTER TABLE `biz_industry`
  ADD COLUMN `knowledge_base_id` BIGINT DEFAULT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）',
  ADD KEY `idx_biz_industry_kb_id` (`knowledge_base_id`);

ALTER TABLE `biz_industry_product`
  ADD COLUMN `knowledge_base_id` BIGINT DEFAULT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）',
  ADD KEY `idx_biz_industry_product_kb_id` (`knowledge_base_id`);

ALTER TABLE `biz_industry_enterprise`
  ADD COLUMN `knowledge_base_id` BIGINT DEFAULT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）',
  ADD KEY `idx_biz_industry_enterprise_kb_id` (`knowledge_base_id`);

ALTER TABLE `biz_industry_market`
  ADD COLUMN `knowledge_base_id` BIGINT DEFAULT NULL COMMENT '关联知识库ID（kb_knowledge_base.id）',
  ADD KEY `idx_biz_industry_market_kb_id` (`knowledge_base_id`);
```

## 4. 后端设计

### 4.1 Entity 字段
在对应 Entity 类新增字段：
```java
@ApiModelProperty("关联知识库ID")
@TableField("knowledge_base_id")
private Long knowledgeBaseId;
```
（需同步更新 XML/Mapper 字段映射）

### 4.2 Controller/API
沿用现有 CRUD 接口，支持 `knowledgeBaseId` 字段的新增/编辑/查询（分页列表可按 `knowledgeBaseId` 筛选，可选）。

### 4.3 跳转语义
“点击行业链接的知识库，可查看知识库的详细内容”——推荐跳转到**知识库详情/文档列表视图**，并按 `knowledgeBaseId` 过滤。

## 5. 前端设计（Vue 管理端）

### 5.1 行业列表页（`views/biz/industry/list/index.vue`）
- 搜索/表单：新增“关联知识库”下拉（数据源：知识库列表 `GET /api/knowledge/base/list` 或分页）
- 新增/编辑弹窗：在表单中增加 `knowledgeBaseId` 选择器（可选，支持清空）
- 列表：新增列“关联知识库”（显示知识库名称）
- 操作：新增“查看知识库”按钮（仅当 `knowledgeBaseId` 不为空）
  - 跳转：`router.push({ path: '/knowledge/document', query: { knowledgeBaseId: row.knowledgeBaseId } })` 或知识库详情页路径

### 5.2 行业产品/企业/市场（Vue）
在各自列表页的**新增/编辑表单**和**详情页**增加“关联知识库”字段及“查看知识库”跳转按钮。

## 6. 前端设计（UniApp）

### 6.1 行业详情页（`pages/industry/detail.vue`）
- 显示“关联知识库”字段（名称）
- 增加“查看知识库”按钮/链接，跳转至知识库文档列表页（带 `knowledgeBaseId` 参数）

### 6.2 行业产品/企业/市场（UniApp）
同上，在详情页增加关联知识库展示与跳转。

## 7. 验证要点
- 字段可为空，不影响现有业务
- 点击跳转能正确带参打开对应知识库
- 新增/编辑保存 `knowledgeBaseId` 正常
