# 知识管理APP页面UI设计规范

当前版本： 1.0.0

---

## 一、设计规范总览

### 1.1 品牌色彩

| 色彩类型 | 色值 | 用途 |
|----------|------|------|
| 品牌主色 | `#25B864` | CTA按钮、导航高亮 |
| 主色按压 | `#1FA057` | 按钮按压态 |
| 主色背景 | `#E8F8EF` | 标签背景 |
| 画布白 | `#FFFFFF` | 页面主背景 |
| 画布柔 | `#F8FAF9` | 区块背景 |
| 表面提升 | `#F1F5F2` | 嵌套卡片 |
| 墨色 | `#1F2329` | 主要文字 |
| 墨色次 | `#646A73` | 次要文字 |
| 墨色弱 | `#8F959E` | 辅助信息 |
| 分割线 | `#DEE0E3` | 边框、分割线 |
| 成功 | `#25B864` | 成功状态 |
| 错误 | `#F54A45` | 错误状态 |

### 1.2 字体规范

**字体栈**：
```css
font-family: -apple-system, 'PingFang SC', 'Helvetica Neue', sans-serif;
```

**字号层级**：

| Token | 字号 | 字重 | 行高 | 用途 |
|-------|------|------|------|------|
| H1 | 24px | 600 | 1.3 | 区块标题 |
| H2 | 20px | 600 | 1.3 | 卡片标题 |
| H3 | 18px | 600 | 1.4 | 列表标题 |
| Body1 | 16px | 400 | 1.6 | 正文大字 |
| Body2 | 14px | 400 | 1.5 | 正文 |
| Caption | 12px | 400 | 1.4 | 辅助文字 |

### 1.3 间距规范

**基础单位**：4px

| Token | 值 | 应用场景 |
|-------|-----|----------|
| xs | 4px | 图标与文字 |
| sm | 8px | 相关元素间 |
| md | 12px | 列表项间距 |
| lg | 16px | 卡片内边距 |
| xl | 24px | 区块间距 |
| xxl | 32px | 大区块间距 |

### 1.4 圆角规范

| Token | 值 | 应用场景 |
|-------|-----|----------|
| sm | 6px | 输入框 |
| md | 8px | 按钮、卡片 |
| lg | 12px | 大卡片 |
| pill | 9999px | 药丸标签 |

## 四、交互规范

### 4.1 转场动画

| 转场类型 | 动画 | 时长 |
|----------|------|------|
| 页面进入 | 从右向左滑入 | 300ms |
| 页面返回 | 从左向右滑出 | 300ms |
| 列表项 | 淡入 | 200ms |

### 4.2 反馈机制

| 操作 | 反馈 |
|------|------|
| 操作成功 | Toast提示 "操作成功" |
| 操作失败 | Toast提示错误信息 |
| 加载中 | Loading动画 |
