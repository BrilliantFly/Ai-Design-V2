## 十、差距优先级分类

### P0 - 核心体验差距（必须修复）
1. 🔴 **编辑器升级**：textarea → 富文本编辑器
2. 🔴 **标签系统修复**：关联kb_tag表，前端接入
3. 🔴 **用户认证接入**：替换硬编码userId=1L
4. 🔴 **文档-目录关联**：创建文档时选择目录

### P1 - 功能完整性差距（应该实现）
1. 🔴 **全文搜索**：跨知识库+小记搜索
2. 🔴 **版本历史**：文档版本追踪+diff+回滚
3. 🔴 **评论系统**：文档评论
4. 🔴 **点赞/收藏**：互动功能
5. 🔴 **图片上传**：文档/小记图片功能
6. 🔴 **分享功能**：生成分享链接
7. 🔴 **成员管理前端**：邀请/移除成员界面
8. 🔴 **知识库封面**：自定义封面图上传

### P2 - 体验优化差距（可以规划）
1. 🟡 **自动保存**：编辑时自动保存草稿
2. 🟡 **左滑删除**：小记左滑删除交互
3. 🟡 **搜索增强**：搜索历史/建议/筛选
4. 🟡 **主题切换入口**：日间/夜间模式切换
5. 🟡 **最近文档流**：首页显示最近编辑文档
6. 🟡 **文档目录导航**：查看页目录侧边栏
7. 🟡 **代码块高亮**：语法高亮+复制按钮
8. 🟡 **时间线分组**：小记按日期分组显示

### P3 - 高级功能差距（长期规划）
1. 🔴 **AI写作助手**
2. 🔴 **思维导图/流程图**
3. 🔴 **数学公式**
4. 🔴 **实时协同编辑**
5. 🔴 **归档功能**
6. 🔴 **统计面板**
