## 三、uni-app 官方 editor 组件

### 3.1 组件说明

`editor` 是 uni-app 官方提供的富文本编辑器组件，基于 `contentEditable` 实现。

### 3.2 使用示例

```html
<template>
  <view class="editor-page">
    <!-- 工具栏 -->
    <view class="toolbar">
      <view :class="formats.bold ? 'active' : ''" 
            class="iconfont icon-bold" 
            data-name="bold" 
            @tap="format" />
      <view :class="formats.italic ? 'active' : ''" 
            class="iconfont icon-italic" 
            data-name="italic" 
            @tap="format" />
      <view class="iconfont icon-image" @tap="insertImage" />
    </view>
    
    <!-- 编辑器 -->
    <editor 
      id="editor" 
      class="ql-container"
      placeholder="开始输入..."
      show-img-size 
      show-img-toolbar 
      show-img-resize
      @ready="onEditorReady"
      @input="updateContent"
    />
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

const formats = ref<any>({})
const editorCtx = ref<any>(null)

const onEditorReady = () => {
  uni.createSelectorQuery().select('#editor').context((res) => {
    editorCtx.value = res.context
  })
}

const format = (e: any) => {
  const { name, value } = e.target.dataset
  if (!name) return
  editorCtx.value.format(name, value)
  formats.value[name] = value
}

const updateContent = (e: any) => {
  const html = e.detail.html
  // 保存到后端
}
</script>
```

### 3.3 平台支持

### 3.4 核心API

| API | 说明 |
|-----|------|
| `setContents` | 设置编辑器内容 |
| `insertImage` | 插入图片 |
| `format(name, value)` | 设置格式 |
| `undo()` | 撤销 |
| `redo()` | 重做 |
| `getContents()` | 获取内容 |

## 四、配合 Quill 使用

uni-app 官方推荐配合 Quill 1.3.7 使用：

```bash
npm install quill@1.3.7
```

在入口文件中注入：

```ts
// #ifdef H5
import Quill from 'quill'
window.Quill = Quill
// #endif
```

## 五、技术选型对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| **uni-app editor + Quill** | 官方支持，跨端兼容，文档完善 | 功能相对基础 |
| **wangEditor** | 国产，功能丰富 | 需web-view适配 |
| **mp-html editable** | 已有组件 | 编辑功能弱，不适合文档编辑 |
| **TinyMCE** | 功能强大 | 收费，体积大 |
| **CKEditor** | 功能完善 | 收费 |

---

## 六、结论

**推荐方案**：使用 **uni-app 官方 editor 组件** + **Quill 1.3.7**

**理由**：
1. 官方维护，稳定性有保障
2. 跨端兼容性好（H5、App、微信小程序）
3. 与 know-uniapp 技术栈一致（Vue3 + TypeScript）
4. 满足基本富文本编辑需求（加粗、斜体、图片、列表等）

**注意事项**：
- 不支持的平台需使用 web-view 降级方案
- 图片上传需自行实现后端接口
- 内部采用 delta 格式存储，导出为 HTML
