# 知识管理APP接口设计文档

当前版本： 1.0.0

---

## 一、接口规范

### 1.1 请求格式

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1704067200000,
  "requestId": "uuid-xxxx"
}
```

### 1.2 分页请求

```json
{
  "pageNum": 1,
  "pageSize": 10,
  "keyword": "搜索关键词"
}
```

### 1.3 分页响应

```json
{
  "code": 200,
  "data": {
    "list": [],
    "total": 100,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

### 1.4 错误码规范

| 错误码 | 说明 |
|--------|------|
| 200 | 成功 |
| 400 | 参数错误 |
| 401 | 未授权 |
| 403 | 禁止访问 |
| 404 | 资源不存在 |
| 500 | 服务器内部错误 |

## 二、知识库模块接口

### 2.1 获取知识库列表

**GET** `/api/knowledge-base/list`

```json
// 请求参数
{
  "pageNum": 1,
  "pageSize": 10
}

// 响应
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": 1,
        "name": "技术文档",
        "icon": "📚",
        "cover": "https://xxx.jpg",
        "description": "记录技术学习和工作中的文档",
        "docCount": 12,
        "visibility": 1,
        "createTime": 1704067200000
      }
    ],
    "total": 5,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

### 2.2 获取知识库详情

**GET** `/api/knowledge-base/{id}`

```json
// 响应
{
  "code": 200,
  "data": {
    "id": 1,
    "name": "技术文档",
    "icon": "📚",
    "cover": "https://xxx.jpg",
    "description": "记录技术学习和工作中的文档",
    "visibility": 1,
    "docCount": 12,
    "createTime": 1704067200000,
    "updateTime": 1704153600000
  }
}
```

### 2.3 创建知识库

**POST** `/api/knowledge-base`

```json
// 请求
{
  "name": "新知识库",
  "icon": "📖",
  "cover": "https://xxx.jpg",
  "description": "知识库描述",
  "visibility": 1
}

// 响应
{
  "code": 200,
  "data": {
    "id": 2,
    "name": "新知识库"
  }
}
```

### 2.4 更新知识库

**PUT** `/api/knowledge-base/{id}`

```json
// 请求
{
  "name": "更新后的名称",
  "description": "更新后的描述"
}

// 响应
{
  "code": 200,
  "message": "更新成功"
}
```

### 2.5 删除知识库

**DELETE** `/api/knowledge-base/{id}`

```json
// 响应
{
  "code": 200,
  "message": "删除成功"
}
```

## 四、文档模块接口

### 4.1 获取知识库文档列表

**GET** `/api/knowledge-base/{id}/document`

```json
// 请求参数
{
  "directoryId": 1,
  "pageNum": 1,
  "pageSize": 10
}

// 响应
{
  "code": 200,
  "data": {
    "list": [
      {
        "id": 1,
        "title": "Vue3组件封装指南",
        "content": {
          "type": "doc",
          "content": [...]
        },
        "contentType": 1,
        "directoryId": 1,
        "viewCount": 128,
        "status": 1,
        "createTime": 1704067200000,
        "updateTime": 1704153600000
      }
    ],
    "total": 10,
    "pageNum": 1,
    "pageSize": 10
  }
}
```

### 4.2 获取文档详情

**GET** `/api/document/{id}`

```json
// 响应
{
  "code": 200,
  "data": {
    "id": 1,
    "title": "Vue3组件封装指南",
    "content": {
      "type": "doc",
      "content": [
        {
          "type": "paragraph",
          "content": [
            {
              "type": "text",
              "text": "文档内容..."
            }
          ]
        }
      ]
    },
    "contentType": 1,
    "directoryId": 1,
    "knowledgeBaseId": 1,
    "viewCount": 128,
    "status": 1,
    "createTime": 1704067200000,
    "updateTime": 1704153600000
  }
}
```

### 4.3 创建文档

**POST** `/api/document`

```json
// 请求
{
  "knowledgeBaseId": 1,
  "directoryId": 1,
  "title": "新文档标题",
  "contentType": 1
}

// 响应
{
  "code": 200,
  "data": {
    "id": 2,
    "title": "新文档标题"
  }
}
```

### 4.4 更新文档

**PUT** `/api/document/{id}`

```json
// 请求
{
  "title": "更新后的标题",
  "content": {}
}

// 响应
{
  "code": 200,
  "message": "保存成功"
}
```

### 4.5 删除文档

**DELETE** `/api/document/{id}`

```json
// 响应
{
  "code": 200,
  "message": "删除成功"
```
