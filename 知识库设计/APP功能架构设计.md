# 知识管理APP功能架构设计

当前版本： 1.0.0

---

## 一、产品定位

面向个人和团队的知识管理平台，提供文档创作和知识库管理功能，帮助用户沉淀、组织、分享知识。

## 三、知识库模块

### 3.1 功能清单

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 知识库创建 | 创建新知识库，设置名称、图标、描述 | P0 |
| 目录管理 | 树形目录结构，支持拖拽排序 | P0 |
| 文档管理 | 新建、编辑、删除、移动文档 | P0 |
| 封面设置 | 自定义知识库封面图 | P1 |
| 知识库设置 | 公开/私密设置 | P1 |

### 3.2 数据结构

```
知识库 (KnowledgeBase)
├── id: Long
├── name: String (知识库名称)
├── icon: String (图标)
├── cover: String (封面图URL)
├── description: String (描述)
├── visibility: Enum (public/private)
├── docCount: Integer (文档数)
├── sort: Integer (排序)
├── status: Integer (状态)
├── createTime: Long
└── updateTime: Long

目录 (Directory)
├── id: Long
├── knowledgeBaseId: Long (所属知识库)
├── parentId: Long (父目录ID, 0为根目录)
├── name: String (目录名称)
├── icon: String (图标)
├── sort: Integer (排序)
├── createTime: Long
└── updateTime: Long

文档 (Document)
├── id: Long
├── directoryId: Long (所属目录)
├── knowledgeBaseId: Long (所属知识库)
├── title: String (标题)
├── content: Text (内容JSON)
├── contentType: Enum (richtext/markdown)
├── viewCount: Integer (浏览次数)
├── sort: Integer (排序)
├── status: Integer (状态)
├── createTime: Long
└── updateTime: Long
```

## 四、文档编辑模块

### 4.1 功能清单

| 功能点 | 说明 | 优先级 |
|--------|------|--------|
| 富文本编辑 | 所见即所得编辑器 | P0 |
| Markdown | 支持Markdown语法 | P0 |
| 标题层级 | H1-H6标题 | P0 |
| 文字样式 | 加粗、斜体、下划线、删除线 | P0 |
| 列表 | 有序列表、无序列表、任务列表 | P0 |
| 代码块 | 代码高亮、语言选择 | P0 |
| 表格 | 插入和编辑表格 | P1 |
| 图片 | 插入图片、拖拽上传 | P1 |
| 附件 | 插入文件附件 | P1 |

```

│   ├── 图片
│   ├── 链接

│   ├── 表格
│   └── 代码块
```

## 六、页面流转图
