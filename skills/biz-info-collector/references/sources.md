# 来源与检索关键词建议

> 目标：用最少的检索拿到最权威、最可溯源的原始资料。**先权威源，后二手源**；每条数据都要能回到 URL。

## 来源优先级

| 级别 | 来源 | 适用 | 备注 |
|------|------|------|------|
| A 权威一手 | 政府部门、统计局、行业协会、上市公司年报/招股书、国家标准 | 市场规模、行业定义、政策、企业工商/财务 | 优先引用 |
| B 专业二手 | 头部研究机构/咨询报告（IDC、艾瑞、Gartner、赛迪等）、券商研报 | 市场规模、增速、竞争格局 | 注明机构与年份 |
| C 公开媒体 | 权威媒体、企业官网/公众号、专业垂直媒体 | 企业动态、产品、渠道、营销 | 需交叉验证 |
| D 企业库 | 企查查/天眼查/爱企查等公开工商信息 | 企业名称、成立时间、注册资本、参保人数、地址 | 仅采公开字段 |

> 多源冲突时：A > B > C；同年取权威，异年取最新并注明。

## 通用检索策略

1. 用 `websearch` 先撒网：`"{行业} 行业报告 filetype:pdf"`、`"{行业} 市场规模 2025"`。
2. 命中权威 PDF/政府页 → 用 `webfetch` 抓正文。
3. 每个结论至少 1 个来源；关键数字（市场规模、增速、营收）尽量 2 个来源交叉。
4. 记录**来源 URL + 发布年份**，写入 `_sources`。
5. 找不到 → 留空，列入报告「待核实」，**不要编造**。

## 分对象关键词模板

### 行业（industry）
- 定义/边界：`"{行业} 行业定义 分类"`
- 技术：`"{行业} 核心技术 技术路线"`
- 产业链：`"{行业} 产业链 上游 中游 下游"`
- 规模/增速：`"{行业} 市场规模 {year} 亿元"`、`"{行业} 行业 CAGR 预测"`
- 格局：`"{行业} 竞争格局 市场份额"`
- 财务：`"{行业} 平均毛利率 净利率"`
- 动态/政策：`"{行业} 政策 {year}"`、`"{行业} 行业趋势"`

### 行业产品（industry_product）
- `"{行业} 主要产品 品类"`、`"{产品} 产品定位 卖点"`
- `"{产品} 用户画像 需求痛点"`、`"{产品} 生命周期 竞争"`

### 行业企业（industry_enterprise）
- 名录：`"{行业} 龙头企业 排行"`、`"{行业} 代表企业 平台"`
- 工商：`"{企业名} 工商信息 注册资本 成立时间 地址"`
- 经营：`"{企业名} 主营业务 产品 营收"`、`"{企业名} 市占率"`
- 竞争：`"{企业名} 竞争对手"`、`"{企业名} 优势 劣势"`

### 行业市场（industry_market）
- 需求/商机：`"{行业} 市场需求 规模 痛点"`、`"{行业} 市场机会"`
- 商业模式：`"{行业} 商业模式 收入来源 成本结构"`
- 竞争/推广：`"{行业} 竞争手段"`、`"{行业} 推广渠道 获客"`
- 价值分配：`"{行业} 产业链 利润分配"`

### 客户 / 客户企业（customer / customer_company）
- 个人（公开人物）：`"{姓名} {职业/机构}"`、`"{姓名} 简介"`
- 企业：`"{企业名} 工商"`、`"{企业名} 主营 产品 规模"`
- 公开联系人/电话：`"{企业名} 联系电话"`（**仅企业公开电话**）
- ⚠️ 个人手机/邮箱/住址/家庭情况：**不采集**。

### 客户画像（customer_profile）
- 无直接来源，基于已采事实**推断**，标注「推断」与依据。
